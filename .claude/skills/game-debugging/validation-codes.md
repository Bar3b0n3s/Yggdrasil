# Validation codes (`project.validate`, `reference/Validation`)

A reference page of the `game-debugging` skill (`skills/game-debugging`).

`project.validate {fix: true}` applies every safe fix; `fix: ["<id or CODE>"]` only the selected ones, as one undoable command. Each diagnostic's `autoFixable` says whether that one can be fixed automatically.

The `PHYSICS_*` codes also report the 2D world (RigidBody2D, BoxCollider2D, CircleCollider2D, PolygonCollider2D, TilemapCollider), naming the 2D component; a CircleCollider2D's `PHYSICS_NONUNIFORM_SCALE` is a scale that differs in X and Y.

| Code | Severity | What it means | Fix |
|---|---|---|---|
| `SCENE_NO_PRIMARY_CAMERA` | Warning | A scene with entities has no Primary camera. | Set Primary on the camera, or add one with `entity.create {components: {Camera: {Primary: true}}}`; the fix makes a scene's only camera Primary. |
| `SCENE_MULTIPLE_PRIMARY_CAMERAS` | Error | Several cameras are Primary. | Clear Primary on all but one; the fix keeps the first in scene order. |
| `SCENE_DUPLICATE_UNIQUE_COMPONENT` | Error | A scene file holds two Environment or PostProcess components. | `scene.open {repair: true}`, then `scene.save`. |
| `SCENE_NONCANONICAL_ORDER` | Warning | A child is listed before its parent in a scene file. | `scene.open {repair: true}`, then `scene.save`. |
| `SCENE_INVALID_HIERARCHY` | Error | A Parent names no entity, or parents form a cycle. | `scene.open {repair: true}`, then `scene.save`. |
| `SCENE_INCONSISTENT_PREFAB_LINK` | Error | A prefab member's PrefabLink does not match its instance root, an OuterPrefabEntityID names no enclosing instance, or a nested instance root records overrides. | `scene.open {repair: true}` (unpacks the member, clears the OuterPrefabEntityID or drops the nested root's overrides), then `scene.save`, or re-instantiate the prefab. |
| `ENTITY_DUPLICATE_ID` | Error | Two entities of a file share an ID. | `scene.open {repair: true}`, then `scene.save`. |
| `ENTITY_DANGLING_REFERENCE` | Warning | An entity reference names no entity of its scene. | Point it at an existing entity; the fix clears it in the open scene. |
| `COMPONENT_FIELD_OUT_OF_RANGE` | Error | A component value in a file fails the registry's checks. | Correct the value through automation, or `scene.open {repair: true}` (drops the component). |
| `COMPONENT_MISSING_REQUIREMENT` | Error | A component lacks a component it requires. | Add the required component, or repair-load the scene. |
| `COMPONENT_CONFLICT` | Error | A component shares its entity with one it excludes. | Remove one of them, or repair-load the scene. |
| `ASSET_MISSING` | Error | A reference names a handle no asset has. | Restore the asset (`edit.undo` of its deletion) or assign another. |
| `ASSET_TYPE_MISMATCH` | Error | A reference names an asset of another type, or a .meta disagrees with its source. | Assign an asset of the accepted type; the fix rewrites a mismatching .meta for the importer that takes the source, keeping its handle. |
| `ASSET_IMPORT_FAILED` | Error | An asset, its .meta or a scene file cannot be imported or loaded. | Fix the source file; `asset.info` shows the failure. |
| `ASSET_ORPHAN_META` | Warning | A .meta has no source file. | Restore the source, or let the fix trash the .meta. |
| `ASSET_DUPLICATE_HANDLE` | Error | Copied .meta files share a handle. | Let the fix give each copy a fresh handle. |
| `ASSET_ORPHAN_DEPENDENCY` | Warning | A dependency .meta names a missing owner. | Restore the owner, or let the fix trash the dependency .meta. |
| `ASSET_TANGENTS_APPROXIMATED` | Warning | A glTF primitive needs tangents but has no UVs. | Export the model with UVs or tangents. |
| `ASSET_UNSUPPORTED_UV_SET` | Warning | A glTF texture uses TEXCOORD_2 or a later set, which is ignored. | Bind it to TEXCOORD_0 or TEXCOORD_1 in the model. |
| `ASSET_VERTEX_COLORS_IGNORED` | Warning | No longer reported: since GltfImporter version 2, `COLOR_0` is imported. | Nothing to fix. |
| `ASSET_CONTENT_SKIPPED` | Warning | A glTF holds content the importer skips: cameras, lights, points or lines (or a primitive without positions), GPU instancing, a texture rotation or an image that is not PNG or JPEG; of skins and animations, more than four joint influences (`JOINTS_1`), more than 32 morph targets, a skin whose joints leave the default scene, a mesh on a joint or one it cannot skin (`nodes[i].skin`), animation channels of nodes that are not joints, of weights no Animator plays or repeating a target, an animation left without channels or shorter than 1 ms, and skins, animations and morph targets under `MergeMeshes`. The subject names the item (`animations[0].channels[2]`). | Rebuild cameras and lights as components; animate other nodes with scripts, parent meshes to nodes that are not joints, and export at most four influences and 32 morph targets. |
| `PATH_CASE_MISMATCH` | Error | A .meta or path matches a file only ignoring case. | Use the exact spelling; the fix renames the .meta. |
| `PREFAB_MISSING_ASSET` | Warning | An instance names an unregistered prefab. | Restore the prefab, or `prefab.unpack` the instance. |
| `PHYSICS_NONCONVEX_DYNAMIC` | Error | A non-convex MeshCollider is on a Dynamic body. | Set Convex, or make the body Static or Kinematic. |
| `PHYSICS_MIXED_TRIGGER` | Error | A body's colliders disagree on IsTrigger. | Make all or none triggers; move triggers to a child with its own body. |
| `PHYSICS_DYNAMIC_TRIGGER` | Error | A Dynamic body has only trigger colliders. | Make it Kinematic or Static, or clear IsTrigger. |
| `PHYSICS_ALL_DOFS_LOCKED` | Error | A Dynamic body has every axis locked. | Unlock an axis, or make it Kinematic or Static. |
| `PHYSICS_INVALID_SHAPE` | Error | A collider shape cannot be created, or a Dynamic body cannot take its shape (on RigidBody's or RigidBody2D's `Mass`: an inertia too large for its Mass); for a TilemapCollider (field `Tilemap`), no tilemap (neither its own nor its TilemapRenderer's), one that is missing or fails to load, or more than 65,536 merged boxes. | Fix its size or scale, or use a mesh with volume; lower the Mass or bring the colliders closer; set the TilemapCollider's or the TilemapRenderer's `Tilemap`, or split a map whose solid cells merge into too many boxes. |
| `PHYSICS_ADJACENT_STATIC_BODIES` | Warning | Touching static bodies make a rolling body bump. | The fix adds a Static RigidBody to their common ancestor (one compound). |
| `PHYSICS_UNKNOWN_LAYER` | Error | A body names an undeclared layer (it uses Default). | Declare it in `Physics.Layers`, or name a declared layer. |
| `PHYSICS_NONUNIFORM_SCALE` | Warning | A sphere or capsule under non-uniform scale. | Use a uniform scale or a box/convex collider. |
| `PHYSICS_DYNAMIC_UNDER_MOVING_PARENT` | Warning | A Dynamic body below a moving ancestor does not follow it. | Move it out from under the ancestor, or make it Kinematic. |
| `PHYSICS_LIMIT_EXCEEDED` | Warning; Error at the limit | Too many bodies for the world's limit. | Merge colliders into compound bodies or remove bodies. |
| `SCRIPT_COMPILE_ERROR` | Error | A script does not compile or fails at load time. | Fix the reported line (`script.check`). |
| `SCRIPT_TYPE_ERROR` | Error; Warning for a Luau lint warning | The strict checker reports a finding other than a syntax error (a type error, an unsupported type function, a require it cannot resolve); one of Luau's lint warnings (an unused local, two statements on one line) is a Warning. | Fix the reported range (`script.check`); the games suite fails a game on either. |
| `SCRIPT_NOT_A_BEHAVIOUR` | Error | A Script component names a Module or TestSuite. | Assign a script that returns `Script.Define`. |
| `SCRIPT_UNKNOWN_FIELD_OVERRIDE` | Error | An override names no declared field. | Remove or rename the override. |
| `SCRIPT_FIELD_TYPE_MISMATCH` | Error | An override does not match its declared type. | Correct the override's value. |
| `INPUT_UNKNOWN_ACTION` | Error | An `Input` call names an undeclared action. | Declare it in `Input.Actions`, or fix the literal. |
| `AUDIO_NO_LISTENER` | Warning | Spatial sources but no primary listener or camera. | Add a Primary AudioListener to the camera or player. |
| `AUDIO_MULTIPLE_PRIMARY_LISTENERS` | Warning | Several listeners are Primary. | Clear all but one; the fix clears the later ones. |
| `RENDER_NO_LIGHTING` | Warning | Non-emissive meshes but no light or ambient light. | Add a light, or raise the environment's intensity. |
| `RENDER_LIGHT_LIMIT_EXCEEDED` | Warning | More enabled lights than one view shades: the project's `Rendering.MaxShadedLights` (256 by default; 512, 1024 or 2048). | Raise `Rendering.MaxShadedLights`, or disable or remove lights. |
| `RENDER_SPOT_SHADOW_BUDGET` | Warning | More than 16 shadow-casting spot lights. | Turn off shadows on less important spot lights. |
| `BUILD_START_SCENE_MISSING` | Error | StartScene names no scene file. | Create it with `scene.new`, or point StartScene at a scene. |
| `BUILD_SCENE_MISSING` | Error | An Export.BuildScenes entry names no scene file. | Create the scene; the fix removes the entry. |
| `TEST_SUITE_INVALID` | Error | A Testing.Suites entry's script is not a TestSuite, or its scene is not a registered scene asset. | Assign a `Test.Suite` script; create and save the scene (so it has its `.meta`), or leave Scene empty. |
| `SCRIPT_COMPUTED_ASSET_LOAD` | Warning | With `Export.PruneUnreferenced` on, an `Assets.Load` computes its path, so a pruned export leaves out an asset only it names. | Pass the path as a string literal, reference the asset from a component or script field, or turn the setting off. |
| `PREFAB_CYCLE` | Error | A prefab nests itself, directly or through other prefabs; a prefab update that would propagate around the cycle is refused. | Remove the nested instance that closes the cycle from one of the named prefab files (cycles come only from hand edits or merges). |
| `SPRITE_UNKNOWN_SORTING_LAYER` | Warning | A SpriteRenderer or TilemapRenderer names a sorting layer that `SortingLayers.Layers` does not declare; it draws in the first layer (the finding names the component). | Declare the layer with `project.setSettings {patch: {SortingLayers: {Layers: [...]}}}`, or correct the name. |
| `SPRITE_FRAME_OUT_OF_RANGE` | Warning | A SpriteRenderer's Frame is not an index of its sprite sheet's frames; it draws nothing, is never picked and has no bounds. | Set Frame below the sheet's frame count, or add the frame to the sheet. |
| `SPRITE_UNKNOWN_CLIP` | Warning | A SpriteAnimator's Clip names no clip of its SpriteRenderer's sprite sheet (or the renderer has no sheet); it plays nothing, and play logs it once per entity and clip. | Name a clip of the sheet (`asset.getProperties` lists its clips), add the clip with `asset.setProperties`, or clear Clip. |
| `PHYSICS2D_MIXED_WORLDS` | Error | An entity holds both 2D (RigidBody2D, a 2D collider) and 3D physics components; it stays in the 3D world and its 2D components make no body. | Remove the components of the world it does not belong to, or split the entity in two. |
| `PHYSICS2D_OFF_PLANE` | Warning | A 2D body's entity (or an ancestor) is rotated about X or Y; the body takes only its rotation about Z, and its write-back drops the tilt. | Rotate the entity and its ancestors about Z only. |
| `TILEMAP_FRAME_OUT_OF_RANGE` | Warning | A `.tilemap`'s palette entry names a frame its sprite sheet does not have (reported on the tilemap file, field `Palette[<i>].Frame`); the cells holding it draw nothing, are never picked and have no bounds. | Set the entry's Frame below the sheet's frame count (`asset.setProperties` on the tilemap), add the frame to the sheet, or repaint the cells with another entry. |
| `SPRITE_FRAME_OUTSIDE_TEXTURE` | Warning | A sprite sheet's frame extends past its texture's size (reported on the sheet file, field `Frames[<i>].Rect`), or a `.tilemap`'s palette entry names such a frame (on the tilemap file, field `Palette[<i>].Frame`); the sprite or the tiles sample the texture's edge texels there. A hand-edited sheet or a texture reimported smaller causes it: `asset.setProperties` refuses such a frame. | Keep the frame's X + Width within the texture's width and Y + Height within its height (`asset.setProperties` on the sheet), reimport the texture at the size the frames expect, or name another frame. |
| `UI_ELEMENT_WITHOUT_CANVAS` | Warning | An entity with a `UiRect` has no `UiCanvas` on an ancestor, so it is never laid out or drawn. | Move it below a canvas (`entity_reparent`), or add a `UiCanvas` to its root; `ui_tree` lists what each canvas holds. |
| `UI_IMAGE_FRAME_OUT_OF_RANGE` | Warning | A `UiImage`'s `Frame` is not an index of its sprite sheet's `Frames`, so it draws nothing. | Set `Frame` below the sheet's frame count (`asset_get_properties` lists them), or add the frame to the sheet. |
| `UI_WIDGET_PART_INVALID` | Warning | A `UiToggle`'s `Graphic`, a `UiSlider`'s `Fill` or `Handle`, a `UiScrollView`'s `Content`, or a `UiTextInput`'s `TextElement` or `Placeholder` names an entity that is not a UI element below the widget in its canvas, so the widget ignores it. | Name an element below the widget (an entity with a `UiRect`, no other `UiCanvas` in between), or clear the reference; `ui_tree` shows each element's parent. |
| `RENDER_POINT_SHADOW_BUDGET` | Warning | More than 16 shadow-casting point lights are enabled in a scene; each view shadows the 16 most important it sees (the four most important at full resolution) and lights the rest without shadows (`stats.get`'s `droppedPointShadows`). | Turn off `CastShadows` on less important point lights, or keep fewer of them in view at once. |
| `ANIMATION_NO_ANIMATOR` | Warning | A `SkinnedMesh`'s mesh has a skin, but no Animator is on its entity or an ancestor; it draws its bind pose. A play session raises it too (once per entity). | Add an Animator with the mesh's Skeleton to the entity or an ancestor (a glTF instance has one on the skin's entity), or remove the `SkinnedMesh`. |
| `ANIMATION_SKELETON_MISMATCH` | Warning | A `SkinnedMesh`'s mesh skin addresses more joints than the Skeleton of its Animator holds; it draws its bind pose. A play session raises it too (once per entity). | Set the Animator's Skeleton to the skin the mesh was imported with (the `skin:<index>` sub-asset of the same glTF). |
| `GRAPH_INVALID` | Error | A visual-scripting graph (a `.graph` source, a Script asset of the Graph importer) does not read or breaks a rule of the node library: an unknown kind or pin, a link between incompatible pins (an optional output into a required input among them), a second link into a data input, a cycle, a literal its input does not take (a zero quaternion among them), an input left unlinked, a `Flow.IfNotNil` `Result` read off its `True` flow (where it may be nil), a loop's `Index` or `Element` read off its `Body` flow into an input that needs a value (nil when the loop ran zero times), a number with more digits than its float keeps (the message names the float to write), a flow nested more than 64 blocks deep or a transpiled text larger than 8 MiB (each at the statement that passes the limit). One finding per problem, at its JSON pointer (`field`, `/Nodes/<i>/Values/<pin>`, `/Links/<i>`), its message naming the node; the graph does not import, and this code is its import failure (never a second `ASSET_IMPORT_FAILED`). | Correct the graph with the graph edit methods (`graph_connect`, `graph_set_values`, `graph_remove_nodes`, `graph_add_node`); flatten a flow nested too deep with a `Flow.Sequence` or by linking several exec outputs into one node, and let fewer statements read long chains of values when the text is too large; `graph_read` lists the same findings by node, and `graph_nodes` the kinds and their pins. |
| `GRAPH_UNREACHABLE_NODE` | Warning | A visual-scripting graph's statement node (one with exec pins) is reached by no event's flow, so it never runs (reported at `/Nodes/<i>` while the graph has no other problem than unfinished inputs). | Link it into an event's flow with `graph_connect`, or remove it with `graph_remove_nodes`. |
| `PROBE_NOT_BAKED` | Warning | An enabled `IrradianceVolume` or `ReflectionProbe` has no `Data`, or its `Data` does not load, so it lights or reflects nothing. | Save the scene, bake its lighting with `lighting.bake` (the editor's Tools > Bake lighting, in an editor launched with `renderer: "vulkan"`) and save it again: the bake writes `Assets/Lighting/<the scene's path below Assets/>/` (`Assets/Scenes/Room.scene` into `Assets/Lighting/Scenes/Room/`) and sets every enabled probe's `Data` (`skills/game-building/effects`). In an editor without a GPU (`renderer: "none"`), a `ReflectionProbe` whose baked `.hdr` has no cooked bake there says its environment bake is deferred, with the hint to start the editor with a GPU once: nothing needs a new lighting bake. |
| `TERRAIN_NO_HEIGHTFIELD` | Warning | A `Terrain` has no `Heightfield`, or its Heightfield does not load as one; it draws nothing, and its `TerrainCollider` makes no body. | Assign a heightfield: `asset.create {type: "Heightfield"}` makes a flat 129 x 129 one and `terrain.importHeightmap {source, path}` converts a 16-bit PNG or RAW heightmap; shape it with `terrain.edit` (`skills/game-building/terrain`). |
| `TERRAIN_SPLAT_NOT_RAW` | Warning | A `Terrain`'s `SplatMap` is not imported as a data texture (Usage Linear and Compression None): its weights are decoded as sRGB colour or blurred by block compression, and `terrain.edit` cannot paint it. | `asset.setImportSettings {asset, settings: {Usage: "Linear", Compression: "None"}}` on the splat map; a splat map `terrain.edit`'s first paint makes is imported that way already. |
| `INPUT_INVALID_ACTION` | Error | An action of `Input.Actions` that `play.start` refuses, one diagnostic per problem at its field (`Input.Actions.<Name>.<Field>[<i>]`): an unknown binding name, a stick axis among a button list (`Bindings`, `Positive`, `Negative`), a `Gamepad` that is not a gamepad axis, or a field its type does not have. The project does not play until it is fixed. | Correct the binding with `project.setSettings`, which refuses a patch of `Input` that leaves any action invalid, each problem located under `/patch`. A trigger (`Gamepad.LeftTrigger`, `Gamepad.RightTrigger`) is a button binding (down past 0.5, up below 0.4); a stick belongs in an Axis action's `Gamepad` (`skills/luau-gameplay/characters-and-input`). |
| `PARTICLE_FRAME_OUT_OF_RANGE` | Warning | A `ParticleLook`'s flipbook range (`FirstFrame`, then `FrameCount` frames, 0 to the sheet's last) is empty or ends past its `SpriteSheet`'s frames; the emitter's particles draw nothing. | Keep `FirstFrame` and `FirstFrame + FrameCount` within the sheet's frame count (`asset.getProperties` on the sheet lists its `Frames`), or set `FrameCount` 0; or add the frames to the sheet (`skills/game-building/effects`). |
| `NAV_MESH_NOT_BAKED` | Warning | A scene's `Navigation` component has no `NavMesh`, or its `NavMesh` does not load; every navigation query finds nothing. | Save the scene, bake its navigation with `navigation_bake` (the editor's Tools > Bake navigation) and save it again (`skills/game-building/navigation`). |
| `NAV_MESH_STALE` | Warning | A scene's static colliders, `NavModifier`s or `Navigation` settings changed after its navigation mesh was baked (the hash of the bake's input differs from the one the mesh stores), or the input can no longer be read (a layer the project does not define, a setting out of range); queries still follow the old mesh. The diagnostic names the scene. | Bake the scene's navigation again with `navigation_bake` and save the scene; fix the `Navigation`'s `Layers` or settings first when the message says the input cannot be read. |
| `PHYSICS_SURFACE_UNUSED` | Warning | A `ColliderSurface` applies to no collider: its entity holds no solid collider of a body the scene creates (no collider component, triggers only, a `CharacterController`'s capsule, 2D colliders only, or the colliders of a body a composition error refuses: `PHYSICS_MIXED_TRIGGER`, `PHYSICS_DYNAMIC_TRIGGER`, `PHYSICS_NONCONVEX_DYNAMIC`, `PHYSICS_ALL_DOFS_LOCKED`, `PHYSICS_LIMIT_EXCEEDED`), so its friction, restitution and surface velocity change no contact. | Give the entity a `BoxCollider`, `SphereCollider`, `CapsuleCollider`, `MeshCollider` or `TerrainCollider` that is not a trigger (a surface applies to the colliders on its own entity only, never to its children's), or remove the `ColliderSurface`. |
| `PHYSICS_JOINT_INVALID` | Error | A `HingeJoint`, `SliderJoint`, `DistanceJoint` or `FixedJoint` cannot be made, the reason in the message: no `RigidBody` with a collider at or above its entity, a `ConnectedBody` naming no entity or no body (also once a connected entity was destroyed during play), an end under a `CharacterController` or a `RigidBody2D`, both ends the same body, a zero `Axis`, equal limits while `UseLimits` holds, or a `MinDistance` above `MaxDistance`. The joint is not created and its bodies move unjoined; in play it is also a script error, once per joint. | Fix the field or the hierarchy the message names: put the joint on a body's entity or a child of it, set `ConnectedBody` to another body or null for the world, give `Axis` a direction, separate the limits (a `FixedJoint` for a joint that does not move), or set `MinDistance` at or below `MaxDistance`. `physics.jointInfo`'s `created` shows whether it is in force. |
| `ANIMATION_ATTACHMENT_INVALID` | Warning | A `BoneAttachment` cannot attach its entity to a joint of the Animator's Skeleton (a bone), or the entity's physics fights the placement, the reason in the message: no Animator above the entity (on its parent or an ancestor), an empty `Bone`, a Skeleton without the joint `Bone` names (the message names up to three close joint names), in play an Animator without a pose (its Skeleton null, not loading or posed to values that are not finite), a `CharacterController` or a Dynamic `RigidBody` on the entity, or solid colliders that move with it and form no Kinematic body of their own (an ancestor's compound rebuilt every step, a static body teleported every step, or, under a `CharacterController`, no body at all, so they collide with nothing). An entity that is not attached keeps its Transform. A play session raises it too (once per entity, logged). | Make the entity a child of the Animator's entity (a model instance's armature) with `entity.reparent` or `Entity:SetParent(armature, false)`, set `Bone` to a joint name exactly as the model names it (glTF node names are kept verbatim), and give an attached entity with solid colliders a `RigidBody` of Type Kinematic; a held object takes no `CharacterController` or Dynamic `RigidBody` (`skills/game-building/prefabs-and-levels`). |
| `RENDER_REFLECTION_INVALID` | Warning | A `PlanarReflection` that reflects nothing or not on its glass: its entity has no `MeshRenderer` with a `Mesh` (nothing would show the reflection), or its mesh's bounds reach farther than 5 cm (after the entity's scale) from its plane, usually a `Normal` along the wrong axis, or a mesh too thick to be one glass. The mirror then shows the probes and SSR, or a wrong reflection. | Put the component on the entity whose `MeshRenderer` draws a flat glass, and set `Normal` to the glass's facing axis in its local axes and `Offset` to its surface: the hint names the axis along which the mesh is thinnest and the `Offset` of its face there, which clears the finding, or says the mesh is too thick (the built-in Quad faces +Z, the Plane +Y). |
| `PHYSICS_MASS_UNUSED` | Warning | A `MassProperties` changes no body: its entity's `RigidBody` makes no Dynamic body (it is Static or Kinematic, its colliders are triggers, or the scene creates no body for it), so its `CenterOfMassOffset` and `InertiaScale` are unused. | Set the `RigidBody`'s `Type` to Dynamic and give the entity a solid collider, or remove the `MassProperties`. |
| `PHYSICS_VEHICLE_INVALID` | Error | A `WheeledVehicle` cannot be made, its first reason the Subject: `body` (its `RigidBody` makes no Dynamic body: no solid collider, Static, Kinematic or a trigger), `wheels` (no `VehicleWheel` below it, or more than 16), `wheel` (a wheel on the vehicle's own entity, or under another `RigidBody` or a `CharacterController`), `collider` (a solid collider on or below a wheel, which the chassis would gather), `suspension`, `engine`, `transmission`, `differential` (a wheel that is not the vehicle's, one wheel twice, none naming a wheel, driven `EngineTorqueRatio` shares that do not sum to 1 within 1e-6, or disabled wheels of the vehicle that leave it no driven wheel or shares off 1, named in the message; a disabled wheel otherwise drops out silently), `bar` or `curve`; in play also `refused`, a description the physics world refuses. The vehicle is not created and its body moves as a plain body. | Fix what the Subject names: a Dynamic `RigidBody` with a solid chassis collider, a child entity with a `VehicleWheel` per wheel and no collider on it, a differential naming the driven wheels (a trailer: one differential, Manual at `Gear` 0), enable the wheels the message names, or the field the message names. |
