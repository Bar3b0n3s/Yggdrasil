# Validation codes

Generated by `Editor --dump-reference` and written by `python Scripts/GenerateDocs.py`; do not edit by hand.

The codes `project.validate` reports (Architecture §13.7), in report order, from `ProjectValidator::GetCodeInfos`; the list keeps the retired codes it no longer reports (`ProjectValidator::GetRetiredCodes`), so that a code is never reused. Each diagnostic is `{id, severity, code, message, entity?, component?, field?, asset?, file?, line?, hint, autoFixable}`; `project.validate {fix: true}` applies every safe fix and `fix: [ids or codes]` only the selected ones, as one undoable command. Auto-fix says whether at least some diagnostics of a code are fixable; each diagnostic's own `autoFixable` is authoritative. Every code but a retired one has a fixture under `Tests/Data/Validation/<CODE>/` that triggers it (coverage gate 6).
