# Validation codes

Generated by `Editor --dump-reference` and written by `python Scripts/GenerateDocs.py`; do not edit by hand.

The codes `project.validate` reports (Architecture §13.7), in report order, from `ProjectValidator::GetCodeInfos`. Each diagnostic is `{id, severity, code, message, entity?, component?, field?, asset?, file?, line?, hint, autoFixable}`; `project.validate {fix: true}` applies every safe fix and `fix: [ids or codes]` only the selected ones, as one undoable command. Auto-fix says whether at least some diagnostics of a code are fixable; each diagnostic's own `autoFixable` is authoritative. Every code has a fixture under `Tests/Data/Validation/<CODE>/` that triggers it (coverage gate 6).

| Code | Severity | Auto-fix | Description | Fix |
|---|---|---|---|---|
| `SCENE_NO_PRIMARY_CAMERA` | Warning | yes | A scene that has entities has no Primary camera, so it renders through none. | Set Primary on the camera the scene renders through or add one with entity.create {components: {Camera: {Primary: true}}}; the fix makes a scene's only camera Primary. |
| `SCENE_MULTIPLE_PRIMARY_CAMERAS` | Error | yes | Several cameras of one scene are Primary, but a scene renders through exactly one. | Clear Primary on all but one camera; the fix keeps the first Primary camera in scene order. |
| `SCENE_DUPLICATE_UNIQUE_COMPONENT` | Error | no | A scene file holds more than one component that is unique per scene (Environment, PostProcess). | Open the scene with scene.open {repair: true}, which keeps the first in canonical order, then scene.save. |
| `SCENE_NONCANONICAL_ORDER` | Warning | no | A scene file lists a child entity before its parent, which is not the canonical order. | Open the scene with scene.open {repair: true}, which normalizes the order, then scene.save. |
| `SCENE_INVALID_HIERARCHY` | Error | no | A scene file has an entity whose Parent names no entity of the scene or forms a parent cycle. | Open the scene with scene.open {repair: true}, which reparents orphans to the root and cuts cycles, then scene.save. |
| `SCENE_INCONSISTENT_PREFAB_LINK` | Error | no | A scene file has a prefab instance member whose PrefabLink does not match its instance root. | Open the scene with scene.open {repair: true}, which unpacks the member, then scene.save, or re-instantiate the prefab. |
| `ENTITY_DUPLICATE_ID` | Error | no | Two entities of a scene file carry the same ID. | Open the scene with scene.open {repair: true}, which gives the later duplicate a fresh ID, then scene.save. |
| `ENTITY_DANGLING_REFERENCE` | Warning | yes | An entity reference field (a component field or a script field override) names no entity of its scene. | Point the reference at an existing entity; the fix in the open scene clears it. |
| `COMPONENT_FIELD_OUT_OF_RANGE` | Error | no | A component value in a scene file fails the registry's checks: a value out of range, of the wrong type or not finite. | Correct the value in the file, or load it with scene.open {repair: true}, which drops the component, and scene.save. |
| `COMPONENT_MISSING_REQUIREMENT` | Error | no | A component in a scene file lacks a component it requires on the same entity. | Add the required component to the entity in the file, or load it with scene.open {repair: true}, which drops the component. |
| `COMPONENT_CONFLICT` | Error | no | A component in a scene file shares its entity with a component it excludes. | Remove one of the two components in the file, or load it with scene.open {repair: true}, which drops the later one. |
| `ASSET_MISSING` | Error | no | A reference in a scene, material or prefab names an asset handle that no asset has; the type's placeholder stands in. | Restore the asset (edit.undo of its deletion, or from version control) or assign another asset. |
| `ASSET_TYPE_MISMATCH` | Error | yes | A reference names an asset of another type than its field accepts, or a .meta's type or importer disagrees with its source's extension. | Assign an asset of the accepted type; the fix rewrites a mismatching .meta for the importer that takes the source, keeping its handle (with that importer's default settings). |
| `ASSET_IMPORT_FAILED` | Error | no | Importing, loading or reading an asset or its .meta failed, or a scene file cannot be loaded at all. | Correct the source file (the message names the failure and its location) or restore it from version control. |
| `ASSET_ORPHAN_META` | Warning | yes | A .meta file has no source file beside it. | Restore the source, or let the fix move the .meta to the trash. |
| `ASSET_DUPLICATE_HANDLE` | Error | yes | Several .meta files whose sources exist carry the same asset handle, typically a copied file pair. | Let the fix give every copy but the original a fresh handle. |
| `ASSET_ORPHAN_DEPENDENCY` | Warning | yes | A dependency .meta names an owner asset that is not registered. | Restore the owner asset, or let the fix move the dependency .meta to the trash. |
| `ASSET_TANGENTS_APPROXIMATED` | Warning | no | A glTF primitive needs tangents but has no TEXCOORD_0, so its tangents are an arbitrary basis. | Export the model with texture coordinates or with its own tangents. |
| `ASSET_UNSUPPORTED_UV_SET` | Warning | no | A glTF texture is bound to TEXCOORD_1, which the engine ignores because meshes have one UV set. | Bind the texture to TEXCOORD_0 in the model, or bake it into the first UV set. |
| `ASSET_VERTEX_COLORS_IGNORED` | Warning | no | A glTF primitive has vertex colours, which the engine ignores. | Bake the colours into a texture or a material, or remove COLOR_0 from the model. |
| `ASSET_CONTENT_SKIPPED` | Warning | no | A glTF file holds content the engine does not import: points or lines, skins, animations, cameras or lights. | Remove the content from the model, or rebuild it with engine components (Camera, lights) in the scene. |
| `PATH_CASE_MISMATCH` | Error | yes | A .meta or a path matches a file only when letter case is ignored, which resolves differently on other systems. | Use the file's exact spelling; the fix renames a .meta to its source's case. |
| `PREFAB_MISSING_ASSET` | Warning | no | A prefab instance names a prefab asset that is not registered; the instance stays fully expanded. | Restore the prefab asset, or unpack the instance (prefab.unpack). |
| `PHYSICS_NONCONVEX_DYNAMIC` | Error | no | A non-convex MeshCollider is on a Dynamic RigidBody, so the body is not created. | Set Convex on the MeshCollider, or make the body Static or Kinematic. |
| `PHYSICS_MIXED_TRIGGER` | Error | no | The colliders gathered by one RigidBody disagree on IsTrigger, so the body is not created. | Make all of the body's colliders triggers or none, moving triggers to a child entity with its own RigidBody. |
| `PHYSICS_DYNAMIC_TRIGGER` | Error | no | A Dynamic RigidBody has only trigger colliders, so the body is not created. | Make the body Kinematic or Static, or clear IsTrigger on its colliders. |
| `PHYSICS_ALL_DOFS_LOCKED` | Error | no | A Dynamic RigidBody has all six degrees of freedom locked, so the body is not created. | Unlock at least one axis, or make the body Kinematic or Static. |
| `PHYSICS_INVALID_SHAPE` | Error | no | A collider's shape cannot be created (a degenerate hull or mesh, or a scale the shape does not allow), so the body is not created. | Correct the collider's size or scale, or use a mesh with a valid volume. |
| `PHYSICS_ADJACENT_STATIC_BODIES` | Warning | yes | Two static bodies touch or nearly touch, so a rolling body bumps at their seam. | Join them into one static compound; the fix adds a Static RigidBody to their nearest common ancestor. |
| `PHYSICS_UNKNOWN_LAYER` | Error | no | A RigidBody or CharacterController names a layer that Physics.Layers does not declare; it uses layer Default. | Declare the layer in Physics.Layers with project.setSettings, or name a declared layer. |
| `PHYSICS_NONUNIFORM_SCALE` | Warning | no | A sphere or capsule collider is under a non-uniform world scale and uses its largest axis. | Give the entity and its ancestors a uniform scale, or use a box or convex mesh collider. |
| `PHYSICS_DYNAMIC_UNDER_MOVING_PARENT` | Warning | no | A Dynamic RigidBody is below an ancestor that moves on its own, and it simulates in world space without following it. | Move the dynamic body out from under the moving ancestor, or make it Kinematic. |
| `PHYSICS_LIMIT_EXCEEDED` | Warning; Error at the limit | no | A scene would create more physics bodies than the world's limit, or more than 90 % of it. | Merge colliders into compound bodies or remove bodies so the count stays below the limit. |
| `SCRIPT_COMPILE_ERROR` | Error | no | A script does not compile, its load-time module code fails, or a require does not resolve. | Correct the script at the reported line (script.check reports the same finding). |
| `SCRIPT_TYPE_ERROR` | Error | no | The strict type checker reports a finding in a script. | Correct the script at the reported range (script.check reports the same finding). |
| `SCRIPT_NOT_A_BEHAVIOUR` | Error | no | A Script component names a script that is a Module or a TestSuite rather than a Behaviour. | Assign a script that returns Script.Define. |
| `SCRIPT_UNKNOWN_FIELD_OVERRIDE` | Error | no | A Script component overrides a field its script does not declare; the override is preserved. | Remove the override, or rename it to a declared field. |
| `SCRIPT_FIELD_TYPE_MISMATCH` | Error | no | A Script component's field override does not match the declared type or constraints; the declared default is used. | Correct the override to match its declared type and constraints. |
| `INPUT_UNKNOWN_ACTION` | Error | no | A string literal passed to an Input action function names no action of Input.Actions. | Declare the action in Input.Actions with project.setSettings, or correct the literal. |
| `AUDIO_NO_LISTENER` | Warning | no | A scene has spatial AudioSources but no primary AudioListener and no primary camera, so they are heard from the origin. | Add an AudioListener with Primary to the camera or the player. |
| `AUDIO_MULTIPLE_PRIMARY_LISTENERS` | Warning | yes | Several active AudioListeners are Primary; the first in canonical order is used. | Clear Primary on all but one AudioListener; the fix clears it on every later one. |
| `RENDER_NO_LIGHTING` | Warning | no | A scene has non-emissive meshes but no light or ambient illumination, so they render black. | Add a light, or raise the environment's effective illumination. |
| `RENDER_LIGHT_LIMIT_EXCEEDED` | Warning | no | A scene has more than 256 enabled lights, more than one view shades. | Disable or remove lights, or keep fewer of them in view at once. |
| `RENDER_SPOT_SHADOW_BUDGET` | Warning | no | A scene has more than 8 shadow-casting spot lights, more than one view shadows. | Turn off shadows on less important spot lights, or keep fewer of them in view at once. |
| `BUILD_START_SCENE_MISSING` | Error | no | StartScene names no scene file. | Create the scene with scene.new, or set StartScene to an existing scene with project.setSettings. |
| `BUILD_SCENE_MISSING` | Error | yes | An Export.BuildScenes entry names no scene file. | Create the scene with scene.new; the fix removes the entry. |
| `TEST_SUITE_INVALID` | Error | no | A Testing.Suites entry names a script that is not a TestSuite, or a scene that does not exist. | Assign a script that returns Test.Suite, and create the scene or leave Scene empty for an empty test scene. |
