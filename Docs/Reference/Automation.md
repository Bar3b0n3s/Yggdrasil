## animation

### animation.preview

Shows an edit scene's Animator posed at a time without playing or changing the scene (no undo step, nothing saved), or ends the preview with stop; scene views, thumbnails and viewport.screenshot show the pose. Edit scenes otherwise draw skinned meshes in their bind pose.

- Flags: tool `animation_preview`, scene target
- Timeout: 60 s
- Required params: `entity`

| Param | Type | Required | Default | Description |
|---|---|---|---|---|
| `entity` | `String` | yes | `""` | The entity whose Animator to preview: its id, a unique id prefix or its path. |
| `time` | `Float` |  | `0` | Seconds added to every layer's time, times the layer's speed, at most a layer time's own bound; absent keeps the running preview's (0 for a new one). |
| `playing` | `Bool` |  | `false` | Whether the editor's frames advance the preview's time; absent keeps the running preview's (false for a new one). |
| `stop` | `Bool` |  | `false` | End the preview, so the entity draws its bind pose again; time and playing are then refused. |

| Result | Type | Description |
|---|---|---|
| `entity` | `EntitySummary` | The previewed entity. |
| `previewing` | `Bool` | Whether a preview runs; false after stop. |
| `time` | `Float` | The preview's time in seconds. |
| `playing` | `Bool` | Whether the editor's frames advance the time. |
| `duration` | `Float` | The longest loaded layer clip's duration in seconds (0 without one). |

Example: Pose the hero half a second into its clips.

```json
{"entity":"/Hero","time":0.5,"playing":false}
```

## asset

### asset.create

Creates a material, a sound effect, a sprite sheet, a tilemap or a string table (with values over the defaults), an empty scene, a prefab of one empty root entity (no values: prefab.create saves a built entity as a prefab), a flat heightfield (no values: terrain.importHeightmap converts a heightmap into one and terrain.edit sculpts it) or a folder below Assets/, with its .meta and any missing parent folders, as one undoable command. A folder that already exists succeeds without a command (created: false), so a Folder op is needed only for an empty folder.

- Flags: tool `asset_create`, mutates, dry run, batch
- Timeout: 60 s
- Required params: `type`, `path`

| Param | Type | Required | Default | Description |
|---|---|---|---|---|
| `type` | `AssetCreateType` | yes | `"Material"` | What to create. |
| `path` | `String` | yes | `""` | The project-relative path below Assets/, with the type's extension (.material, .scene, .prefab, .sfx, .spritesheet, .tilemap, .stringtable; none for a folder); missing parent folders are created with it. |
| `values` | `Variant` |  | `null` | A Material's, a SoundEffect's, a SpriteSheet's, a Tilemap's or a StringTable's fields over the defaults (registry names, such as Roughness, Layers, which a sound effect needs, a sheet's Texture, Frames and Clips, whose frames must lie inside a texture that loads, a tilemap's CellSize, ChunkSize, Palette and Chunks, or a table's Locales and Entries; a material's maps, a sheet's Texture and a palette entry's Sheet take any asset reference: a handle, an Assets/ path or an engine:// path; a sheet's imported Texture is set to Compression None in the same step, so sprite art is never block-compressed). A Scene, a Prefab, a Heightfield and a Folder take no values and refuse them: a prefab is created with one empty root entity, and prefab.create saves an entity built in a scene, its components and children, as a prefab; a heightfield is created flat, and terrain.importHeightmap converts a heightmap into one and terrain.edit sculpts it. |

| Result | Type | Description |
|---|---|---|
| `asset` | `AssetSummary` | The created asset; an empty id and type None for a folder. |
| `path` | `String` | The project-relative path created. |
| `undoIndex` | `UInt32` | The command's undo index; 0 in a dry run or a batch, and when nothing was created. |
| `created` | `Bool` | Whether anything was created: false only for a Folder whose path is already a folder, which succeeds without a command. |

Example: Create a red material.

```json
{"type":"Material","path":"Assets/Materials/Red.material","values":{"BaseColor":[0.9,0.15,0.15,1],"Roughness":0.45}}
```

Example: Create a two-note coin pickup sound.

```json
{"type":"SoundEffect","path":"Assets/Audio/Coin.sfx","values":{"Layers":[{"Wave":"Square","Notes":["B5:0.05","E6:0.2"]}]}}
```

Example: Create a sprite sheet with two 16 x 16 frames of a texture and a looping clip over them.

```json
{"type":"SpriteSheet","path":"Assets/Sprites/Hero.spritesheet","values":{"Texture":"4a1c0e7d2b9f3a65","Frames":[{"Name":"Idle0","Rect":{"X":0,"Y":0,"Width":16,"Height":16},"Pivot":[0.5,1]},{"Name":"Idle1","Rect":{"X":16,"Y":0,"Width":16,"Height":16},"Pivot":[0.5,1]}],"Clips":[{"Name":"Idle","Frames":[{"Frame":0,"Ticks":10},{"Frame":1,"Ticks":10}]}]}}
```

Example: Create a string table with an English and a French string for one key.

```json
{"type":"StringTable","path":"Assets/Text/Menu.stringtable","values":{"Locales":["en","fr"],"Entries":[{"Key":"Menu.Start","Values":{"en":"Start","fr":"Commencer"}}]}}
```

Example: Create a flat heightfield for a Terrain.

```json
{"type":"Heightfield","path":"Assets/Terrain/Ground.heightfield"}
```

### asset.delete

Moves an asset with its .meta (and a glTF's dependency files) to Library/Trash as one undoable command; never a permanent delete. A folder below Assets/ that holds no files (only empty folders) is removed, also undoably; a folder that holds files is refused (Validation, naming them): delete its assets first.

- Flags: tool `asset_delete`, mutates, batch
- Timeout: 60 s
- Required params: `asset`

| Param | Type | Required | Default | Description |
|---|---|---|---|---|
| `asset` | `String` | yes | `""` | The asset to move to the trash (a source, not a sub-asset), or a folder below Assets/ that holds no files, to remove. |

| Result | Type | Description |
|---|---|---|
| `asset` | `AssetSummary` | The asset as it was; for a folder its path, with an empty id and type None. |
| `trashDirectory` | `String` | Where its files went: "Library/Trash/\<entry>"; empty for a folder, which holds none. |
| `trashedFiles` | `Array<String>` | The old paths of every file trashed, .meta files and dependency files included. |
| `removedFolders` | `Array<String>` | A folder delete: the folder and every empty folder below it, project-relative and sorted; empty for an asset. |
| `undoIndex` | `UInt32` | The command's undo index; 0 in a batch. |

Example: Delete an unused material.

```json
{"asset":"Assets/Materials/Old.material"}
```

### asset.import

Copies a file (and a glTF's buffers and images) into a folder below Assets/ with its .meta files as one undoable command, then imports it; resolves when the import completed. With replace: true it gives an imported asset the file's new bytes instead, keeping its handle, settings and every sub-asset handle whose key remains, and lists the sub-assets kept, added and removed; a new file that does not import is refused (ImportFailed) and nothing is written (dryRun previews a replace).

- Flags: tool `asset_import`, mutates, dry run, pending
- Timeout: 300 s
- Required params: `source`, `destDir`

| Param | Type | Required | Default | Description |
|---|---|---|---|---|
| `source` | `String` | yes | `""` | The file to import: an absolute native path, or a project path. |
| `destDir` | `String` | yes | `""` | The project-relative folder below Assets/ to copy it into; created when missing. With replace, the folder holding the asset to replace (the file of the source's name there), or that asset's source file itself. |
| `settings` | `Variant` |  | `null` | Import settings merged over the importer's defaults; null for the defaults (with replace, null keeps the asset's settings). |
| `replace` | `Bool` |  | `false` | Give an imported asset this file's bytes instead of importing a new one: the file (and a glTF's changed buffers and images) is written over the asset's, which keeps its .meta, handle and settings, and is reimported; sub-assets keep their handles wherever their keys still exist. The new file is imported in memory first: one that does not import is refused (ImportFailed) and nothing is written. Only the files whose bytes change are written, as one undoable command; dryRun previews it. |

| Result | Type | Description |
|---|---|---|
| `asset` | `AssetSummary` | The imported asset. |
| `subAssets` | `Array<AssetSummary>` | Its sub-assets. |
| `copiedFiles` | `Array<String>` | The files copied with their .meta files, project-relative, sorted; with replace, the files written (in a dry run, those it would write). |
| `diagnostics` | `Array<AssetDiagnosticInfo>` | The importer's warnings. |
| `undoIndex` | `UInt32` | The undo index of the copy; 0 in a batch, in a dry run, and for a replace that changed no file. |
| `keptSubAssets` | `Array<AssetSubAssetInfo>` | With replace: the sub-assets whose keys the new version still has, their handles unchanged, so references to them keep working. |
| `addedSubAssets` | `Array<AssetSubAssetInfo>` | With replace: the sub-assets the new version adds. |
| `removedSubAssets` | `Array<AssetSubAssetInfo>` | With replace: the sub-assets the new version no longer has; project.validate reports what still references them (ASSET_MISSING). |
| `unreferencedFiles` | `Array<String>` | With replace: the files the previous version referenced that the new one does not, left in place (never deleted). |
| `rebuildDiagnostics` | `Array<PrefabRebuildDiagnostic>` | With replace of a prefab: the diagnostics of the rebuilds of the open scenes' instances, every override they dropped among them (also logged). |

Example: Import a glTF model with its textures.

```json
{"source":"C:/Downloads/Kart/Kart.gltf","destDir":"Assets/Models"}
```

Example: Replace the imported Assets/Models/Kart.gltf with a new version of the file.

```json
{"source":"C:/Downloads/Kart/Kart.gltf","destDir":"Assets/Models","replace":true}
```

### asset.setProperties

Applies an RFC 7386 merge patch to a native asset's properties (a material, a sound effect, a sprite sheet, a tilemap or a string table; an array such as a sheet's Frames or a tilemap's Palette is replaced whole) and writes it, as one undoable command. A material's change shows in a running play session's next rendered frame, lockstep, recording, replay and test sessions included, and changes no state hash (a material is only drawn); for any other asset, a running lockstep, recording, replay or test session sees the change only after it ends: those asset reloads are deferred like script reloads.

- Flags: tool `asset_set_properties`, mutates, dry run, batch
- Timeout: 60 s
- Required params: `asset`, `values`

| Param | Type | Required | Default | Description |
|---|---|---|---|---|
| `asset` | `String` | yes | `""` | The native asset (a material, a sound effect, a sprite sheet, a tilemap or a string table). |
| `values` | `Variant` | yes | `null` | An RFC 7386 merge patch of its properties: members replace, null resets a field, an array is replaced whole; a material's maps, a sprite sheet's Texture and a tilemap palette entry's Sheet take any asset reference (a handle, an Assets/ path or an engine:// path); a sprite sheet's imported Texture is set to Compression None in the same step; a tilemap's ChunkSize set without Chunks keeps its painted cells, laid in chunks of the new size. |

| Result | Type | Description |
|---|---|---|
| `asset` | `AssetSummary` | The asset. |
| `values` | `Variant` | Every property after the patch. |
| `undoIndex` | `UInt32` | The command's undo index; 0 when nothing changed, in a dry run or a batch. |

Example: Make a material metallic.

```json
{"asset":"Assets/Materials/Red.material","values":{"Metallic":1}}
```

### input.record

Starts a tick-zero recording or saves its validated applied inputs, expectations and state-hash checkpoints (one every 60 ticks). Stop checks output write permission. Every recording is first replayed with its input events, if any (the verification, which replaces the play session as input.replay does): unless that run reproduces every checkpoint, the final hash and every expectation and raises no script error, Stop refuses to write it (Validation naming the first divergence, the run's outcome in error data verification), which catches a script.eval that wrote script state during the recording. Once the run passed, its scripts are stopped, and an error their OnDestroy raises refuses the recording too (named at teardown). A recording without input events is then written, and the play session is the verification's, paused at its final tick with its scripts stopped (script.eval in the play context is refused there; scene.query and entity.get read its final state). One with input events is then replayed without them (the input check); when that run also reproduces every checkpoint, the final hash and every expectation, whatever script errors it raises, the recording's outcome does not depend on its input and Stop refuses to write it (Validation, the check's outcome in error data inputCheck). The play session is then the last run's, paused where it ended. End such a recording while the played state is still in the scene. While Stop replays the recording it reports $/progress (run 2, with its input, then, for a recording with input events, run 3, without it, at their ticks), and the MCP bridge waits for it as long as that progress advances: timeoutSeconds bounds only a stretch without progress.

- Flags: tool `input_record`, runtime, pending
- Timeout: 600 s
- Required params: `action`

### input.replay

Afterwards the session stays paused at the replay's last tick (or where playback stopped), so script.eval, scene.query and entity.get read its final state; play.stop ends it. While it plays it reports $/progress (its tick of the replay's final tick), and the MCP bridge waits for it as long as that progress advances: timeoutSeconds bounds only a stretch without progress.

### prefab.apply

| `annotate` | `Variant` |  | `null` | Capture-only annotations: labels=all, selection (selected), none or an EntityRef array; colliders, bounds, axes and navMesh (the scene's baked navigation mesh as polygon edges) are booleans. Unknown members and invalid references are rejected. |
| `maxDimension` | `UInt32` |  | `1024` | The larger side of the PNG at most this many pixels, the image downscaled to fit. Absent, it is the larger of width and height when either is given, so the PNG has the requested size, and 1024 otherwise. |
| `inline` | `Bool` |  | `false` | Also return the PNG as base64 in "data" when it is at most 30 KB; a larger one is only written (inlineOmitted). |
| `keep` | `Bool` |  | `false` | Write the PNG into Library/Automation/Kept/ (user://Automation/Kept/ without a writable project and in the Runtime), which no later editor session prunes, instead of Library/Automation/Out/. |

| Result | Type | Description |
|---|---|---|
| `view` | `ViewportView` | The view rendered. |
| `target` | `SceneTarget` | The scene rendered. |
| `camera` | `EntitySummary` | The camera entity the view was rendered through; every member empty for the editor's scene-view camera. |
| `path` | `String` | The PNG's absolute path. |
| `mimeType` | `String` | "image/png". |
| `width` | `UInt32` | The PNG's width in pixels. |
| `height` | `UInt32` | The PNG's height in pixels. |
| `data` | `String` | With inline: the PNG, base64, when it is at most 30 KB; empty otherwise. |
| `inlineOmitted` | `Bool` | True when inline was asked for but the PNG is larger than 30 KB: data is empty and the PNG is at path. |

Example: A 512-pixel screenshot of the game view.

```json
{"view":"game","maxDimension":512}
```

Example: A 320x180 view through the camera entity /SideCamera.

```json
{"view":"game","camera":"/SideCamera","width":320,"height":180}
```

## water

### water.sample

Samples the water surface under world points, as scripts and the physics read it: per point the water that holds it (the Rectangle whose volume holds it with the highest surface there, else the scene's Ocean), or a given water's own surface, with the height, normal, velocity and depth there and whether the point is under water; at a given world time, else 0 in the edit scene and the world's time in the play scene.

- Flags: runtime, batch, scene target
- Timeout: 60 s
- Required params: `points`

| Param | Type | Required | Default | Description |
|---|---|---|---|---|
| `points` | `Array<Vec3>` | yes | `[]` | The world points to sample under, as [x, y, z], 1 to 4096 of them, each coordinate within 1e9 m. |
| `entity` | `String` |  | `""` | An entity with a Water (16 hex digits, a unique id prefix or a path): that water's own surface, other waters' masks aside; omitted: the water that holds each point. |
| `time` | `Float` |  | `0` | The world time to sample at, in seconds; omitted: 0 in the edit scene, the world's time now (the world tick times the fixed delta) in the play scene. |
| `target` | `SceneTarget` |  | `"Edit"` | The scene to read; omitted: the play scene while playing, else the edit scene. |

| Result | Type | Description |
|---|---|---|
| `scene` | `SceneSummary` | The scene sampled. |
| `time` | `Float` | The world time sampled at, in seconds. |
| `points` | `Array<WaterSamplePoint>` | The surface under each point, in the order of the params' points. |

Example: Read the sea's height and depth at two points.

```json
{"points":[[0,0,0],[12.5,-1,40]]}
```

Example: Read the pool's own surface over a point at 2.5 s.

```json
{"points":[[3,2,-6]],"entity":"/Pool","time":2.5}
```
