# File formats

Generated by `Editor --dump-reference` and written by `python Scripts/GenerateDocs.py`; do not edit by hand.

Every authored file is UTF-8 JSON with LF line ends and tabs, written by the canonical writer: `Format` and `Version` first, keys in registry order, PascalCase keys, floats in their shortest round-trip form and default values written out (Architecture §6). Unknown fields warn; unknown components warn and are preserved on save, their numbers written as floats like every authored number, and one holding a fractional number outside the float range, which could not be written back, is `SCENE_INVALID_COMPONENT` (an error in a strict load, dropped by a repair load). `Editor --strict` makes unknown keys, fields and components errors and refuses a project any of whose scenes and prefabs does not load strictly. A newer `Version` than the reader supports fails with `UnsupportedVersion`. Each format has a JSON Schema (draft 2020-12, the subset the engine's validator supports) in `Schemas/`.

### AssetMeta (`.meta`)

The sidecar of every asset file (§6.4): its handle, type, importer, import settings and sub-assets; or, for a file a glTF references, a dependency meta naming its owner.

Header: `"Format": "AssetMeta", "Version": 1`. Schema: [Schemas/AssetMeta.schema.json](Schemas/AssetMeta.schema.json).

```json
{
	"Format": "AssetMeta",
	"Version": 1,
	"Handle": "8c5e9fa7d7637795",
	"Type": "Texture",
	"Importer": "Texture",
	"ImporterVersion": 1,
	"Settings": {
		"Usage": "Color",
		"GenerateMips": true
	},
	"SubAssets": []
}
```

### BatchRequest (`.jsonl`)

One line of an automation batch file (§6.7): `{"method", "params"}`; `{"$ref": "<line>.<jsonPath>"}` inside params references an earlier result. Lines have no Format header.

Schema: [Schemas/BatchRequest.schema.json](Schemas/BatchRequest.schema.json).

```json
{"method":"entity.create","params":{"name":"Ball","components":{"Transform":{"Translation":[0,2,0]}}}}
```

### Replay (`.replay`)

A recorded input replay (§6.7): the start scene and parameters, the seed and rate, the input events per tick, Luau expectations, the state-hash checkpoints the recording observed (one every 60 ticks before the final tick) and the final state hash. The state hash covers the simulated world: every entity with its serialized components, the tick, the session's Random state, the id draws and every body's physics state; it never covers script tables (self.State, module locals), audio or input, which expectations observe instead. Verification with strictHash compares each checkpoint as playback reaches it and stops at the first that differs. A recording with input events is refused when a run without them reproduces every checkpoint, the final hash and every expectation. Version 1 files (no checkpoints) are read as version 2 with none, and project.upgrade rewrites them.

Header: `"Format": "Replay", "Version": 2`. Schema: [Schemas/Replay.schema.json](Schemas/Replay.schema.json).

```json
{
	"Format": "Replay",
	"Version": 2,
	"Scene": {
		"Handle": "8a61c0d2e4f31b77",
		"Path": "Assets/Scenes/Level2.scene"
	},
	"Parameters": {
		"Time": 61.25
	},
	"Seed": 7,
	"FixedHz": 60,
	"EngineVersion": "0.1.0",
	"Config": "Editor",
	"Events": [
		{
			"Tick": 0,
			"Type": "Action",
			"Name": "MoveZ",
			"Value": 1
		},
		{
			"Tick": 100,
			"Type": "Action",
			"Name": "Jump",
			"State": "Tap"
		},
		{
```

### SoundEffect (`.sfx`)

A procedural sound effect (§6.6): layers of oscillators synthesized into a 48 kHz mono clip. Each layer plays notes such as `"C#5:0.06"` (name with `#` or `b`, octave 0 to 8, seconds) and rests such as `"R:0.1"`, or one frequency sweep; the tables below list every field, its range and the limits.

Header: `"Format": "SoundEffect", "Version": 1`. Schema: [Schemas/SoundEffect.schema.json](Schemas/SoundEffect.schema.json).

```json
{
	"Format": "SoundEffect",
	"Version": 1,
	"Seed": 7,
	"Volume": 0.7,
	"Layers": [
		{
			"Wave": "Square",
			"DutyCycle": 0.5,
			"Notes": ["C5:0.06", "E5:0.06", "G5:0.06", "C6:0.18"],
			"Envelope": {
				"Attack": 0.005,
				"Decay": 0.05,
				"Sustain": 0.6,
				"Release": 0.08
			},
			"Volume": 0.6
		}
	]
}
```

#### Fields of SoundEffect

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Seed` | `UInt32` | `0` |  |  |  | The seed of the noise layers' generators. |
| `Volume` | `Float` | `1` | 0 to 1 |  |  | The sound's linear volume, from 0 to 1. |
| `Layers` | `Array<SoundLayer>` | `[]` |  |  |  | 1 to 16 layers, summed. A layer lasts its Delay, plus its notes' seconds (or its Duration), plus its Envelope's Release; the sound lasts as long as its longest layer, at most 10 seconds. |

#### Fields of SoundLayer

One oscillator of a sound effect: a note sequence (Notes) or, without notes, one tone sweeping from StartFrequency to EndFrequency over Duration. Every note, or the tone, plays with its own Envelope.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Wave` | `SoundWave` | `"Square"` |  |  |  | The oscillator's waveform. |
| `DutyCycle` | `Float` | `0.5` | 0.01 to 0.99 |  |  | Square waves only: the fraction of each period spent high. |
| `Notes` | `Array<String>` | `[]` |  |  |  | At most 256 notes played back to back, each "\<Name>\<Octave>:\<seconds>" such as "C5:0.06", or "R:\<seconds>" for a rest such as "R:0.1". Name is C, C#, Db, D, D#, Eb, E, F, F#, Gb, G, G#, Ab, A, A#, Bb or B (case-sensitive: '#' sharpens, 'b' flattens); Octave is one digit, 0 to 8, with A4 = 440 Hz in equal temperament and C4 middle C; seconds is a positive plain decimal (no exponent or sign) with at most 7 digits before and 8 after the point. Empty: the layer plays one tone of Duration seconds. |
| `Duration` | `Float` | `0.1` | 0 to 10 | s |  | Without notes: the sweep's length in seconds. |
| `StartFrequency` | `Float` | `440` | 20 to 20000 | Hz |  | Without notes: the sweep's first frequency. |
| `EndFrequency` | `Float` | `440` | 20 to 20000 | Hz |  | Without notes: the sweep's last frequency (an exponential glide). |
| `Volume` | `Float` | `1` | 0 to 1 |  |  | The layer's linear volume, from 0 to 1. |
| `Envelope` | `SoundEnvelope` | `{"Attack":0.005,"Decay":0,"Sustain":1,"Release":0.01}` |  |  |  | The volume envelope of each note. |
| `LowPass` | `Float` | `0` | 0 to 20000 | Hz |  | The cutoff of a one-pole low-pass filter in Hz; 0 leaves the layer unfiltered. |
| `Delay` | `Float` | `0` | 0 to 10 | s |  | Seconds from the sound's start until the layer starts. |

#### Fields of SoundEnvelope

The ADSR volume envelope every note of a layer plays with.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Attack` | `Float` | `0.005` | 0 to 10 | s |  | Seconds from silence to full level at the note's start. |
| `Decay` | `Float` | `0` | 0 to 10 | s |  | Seconds from full level down to the sustain level. |
| `Sustain` | `Float` | `1` | 0 to 1 |  |  | The level held until the note ends, from 0 to 1. |
| `Release` | `Float` | `0.01` | 0 to 10 | s |  | Seconds from the sustain level to silence after the note ends. |

#### Values of SoundWave

The oscillator of a sound effect layer.

| Value | Description |
|---|---|
| `Sine` | A pure sine tone. |
| `Square` | A square wave with an adjustable duty cycle: hollow, chiptune-like. |
| `Triangle` | A triangle wave: soft, flute-like. |
| `Saw` | A sawtooth wave: bright and buzzy. |
| `Noise` | Seeded noise, resampled at the frequency: hiss, hits and explosions. |

### SpriteSheet (`.spritesheet`)

A sprite sheet (§6.9): one texture, the frames cut from it (texel rectangles, x right and y down from the texture's top-left corner, each with a pivot and 9-slice borders) and named clips that show frames, by their index in `Frames`, for a number of fixed-step ticks. A null `Texture` draws the frames as opaque white. The tables below list every field, its range and the limits.

Header: `"Format": "SpriteSheet", "Version": 1`. Schema: [Schemas/SpriteSheet.schema.json](Schemas/SpriteSheet.schema.json).

```json
{
	"Format": "SpriteSheet",
	"Version": 1,
	"Texture": "4a1c0e7d2b9f3a65",
	"Frames": [
		{
			"Name": "Idle0",
			"Rect": {
				"X": 0,
				"Y": 0,
				"Width": 8,
				"Height": 8
			},
			"Pivot": [0.5, 1],
			"Borders": {
				"Left": 0,
				"Top": 0,
				"Right": 0,
				"Bottom": 0
			}
		},
		{
			"Name": "Idle1",
			"Rect": {
				"X": 8,
				"Y": 0,
				"Width": 8,
				"Height": 8
			},
			"Pivot": [0.5, 1],
			"Borders": {
				"Left": 0,
				"Top": 0,
				"Right": 0,
				"Bottom": 0
			}
		},
		{
			"Name": "Panel",
			"Rect": {
				"X": 0,
				"Y": 8,
				"Width": 12,
				"Height": 6
			},
			"Pivot": [0.5, 0.5],
			"Borders": {
				"Left": 3,
				"Top": 2,
				"Right": 4,
				"Bottom": 1
			}
		}
	],
	"Clips": [
		{
			"Name": "Idle",

```

#### Fields of SpriteSheet

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Texture` | `AssetRef(Texture)` | `null` |  |  |  | The texture the frames are cut from; null draws the frames as opaque white. |
| `Frames` | `Array<SpriteFrame>` | `[]` |  |  |  | At most 65536 frames; a frame's identity is its index. |
| `Clips` | `Array<SpriteClip>` | `[]` |  |  |  | At most 1024 clips, in authored order. |

#### Fields of SpriteFrame

One frame of a sprite sheet: a rectangle of its texture with a pivot and 9-slice borders. Clips and sprites refer to it by its index.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Name` | `String` | `""` |  |  |  | An optional label of at most 128 bytes, without control characters, unique among the frames when not empty. |
| `Rect` | `SpriteRect` | `{"X":0,"Y":0,"Width":1,"Height":1}` |  |  |  | The frame's texel rectangle. |
| `Pivot` | `Vec2` | `[0.5,0.5]` | 0 to 1 |  |  | The point of the frame placed at its sprite's position, as a fraction of the frame's size from its top-left corner: (0.5, 0.5) is its centre, (0.5, 1) the middle of its bottom edge. |
| `Borders` | `SpriteBorders` | `{"Left":0,"Top":0,"Right":0,"Bottom":0}` |  |  |  | The frame's 9-slice insets. |

#### Fields of SpriteRect

A frame's rectangle in its texture, in whole texels: x right and y down from the texture's top-left corner.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `X` | `UInt32` | `0` | 0 to 16383 | texels |  | The texel column of the frame's left edge. |
| `Y` | `UInt32` | `0` | 0 to 16383 | texels |  | The texel row of the frame's top edge (row 0 is the texture's top row). |
| `Width` | `UInt32` | `1` | 1 to 16384 | texels |  | The frame's width; X + Width is at most 16384. |
| `Height` | `UInt32` | `1` | 1 to 16384 | texels |  | The frame's height; Y + Height is at most 16384. |

#### Fields of SpriteBorders

A frame's 9-slice insets in texels: the corners keep their size and the edges and the centre stretch when the frame is drawn larger. All zero: the frame is not sliced.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Left` | `UInt32` | `0` | 0 to 16384 | texels |  | The left inset; Left + Right is at most the frame's Width. |
| `Top` | `UInt32` | `0` | 0 to 16384 | texels |  | The top inset; Top + Bottom is at most the frame's Height. |
| `Right` | `UInt32` | `0` | 0 to 16384 | texels |  | The right inset. |
| `Bottom` | `UInt32` | `0` | 0 to 16384 | texels |  | The bottom inset. |

#### Fields of SpriteClip

A named animation over a sprite sheet's frames, driven by fixed-step ticks.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Name` | `String` | `""` |  |  |  | The clip's name, which scripts play it by: 1 to 128 bytes without control characters, unique among the clips. |
| `Frames` | `Array<SpriteClipFrame>` | `[]` |  |  |  | 1 to 1024 steps, played in order. |
| `Loop` | `Bool` | `true` |  |  |  | Whether the clip starts again after its last step; otherwise it holds its last frame. |

#### Fields of SpriteClipFrame

One step of a sprite clip: a frame shown for a number of fixed-step ticks.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Frame` | `UInt32` | `0` | 0 to 65535 |  |  | The index of the frame in the sheet's Frames, from 0. |
| `Ticks` | `UInt32` | `1` | 1 to 65535 | ticks |  | How many fixed-step ticks the frame shows. |
