# File formats

Generated by `Editor --dump-reference` and written by `python Scripts/GenerateDocs.py`; do not edit by hand.

Every authored file is UTF-8 JSON with LF line ends and tabs, written by the canonical writer: `Format` and `Version` first, keys in registry order, PascalCase keys, floats in their shortest round-trip form and default values written out (Architecture §6). Unknown fields warn; unknown components warn and are preserved on save, their numbers written as floats like every authored number, and one holding a fractional number outside the float range, which could not be written back, is `SCENE_INVALID_COMPONENT` (an error in a strict load, dropped by a repair load). `Editor --strict` makes unknown keys, fields and components errors and refuses a project any of whose scenes and prefabs does not load strictly. A newer `Version` than the reader supports fails with `UnsupportedVersion`. Each format has a JSON Schema (draft 2020-12, the subset the engine's validator supports) in `Schemas/`.

### AssetMeta (`.meta`)

The sidecar of every asset file (§6.4): its handle, type, importer, import settings and sub-assets; or, for a file a glTF references, a dependency meta naming its owner.

Header: `"Format": "AssetMeta", "Version": 1`. Schema: [Schemas/AssetMeta.schema.json](Schemas/AssetMeta.schema.json).

```json
{
	"Format": "AssetMeta",
	"Version": 1,
	"Handle": "8c5e9fa7d7637795",
	"Type": "Texture",
	"Importer": "Texture",
	"ImporterVersion": 2,
	"Settings": {
		"Usage": "Color",
		"GenerateMips": true,
		"Compression": "Auto"
	},
	"SubAssets": []
}
```

### BatchRequest (`.jsonl`)

One line of an automation batch file (§6.7): `{"method", "params"}`; `{"$ref": "<line>.<jsonPath>"}` inside params references an earlier result. Lines have no Format header.

Schema: [Schemas/BatchRequest.schema.json](Schemas/BatchRequest.schema.json).

```json
{"method":"entity.create","params":{"name":"Ball","components":{"Transform":{"Translation":[0,2,0]}}}}
```

### Graph (`.graph`)

A visual-scripting graph (§6.11): one behaviour, whose fields, variables, methods, nodes and links GraphImporter transpiles to Luau and compiles into a Script asset, so a graph fills a script slot as a `.luau` behaviour does. A node is a node kind of the library (`graph.nodes` lists them) with literals of its input pins; a link joins an output pin to an input pin of another node. Every list is in its canonical order (fields, variables and methods by Name, nodes by Id, links by From and To), so each write of a graph is byte-identical; the `graph.*` methods edit it. A field's, variable's or method's `Name` is a Luau identifier of 1 to 64 bytes, not a reserved word, not starting with `__` and not a reserved script field name (`Entity`, `Fields`, the callbacks; for a method also not `RunsWhileWorldPaused`), unique across the three lists; a field's or variable's `Default` has its `Kind`'s spelling (a Number a finite number, an Integer an int32, a Bool a boolean, a String a string of at most 4,096 bytes, a Vector `[x, y, z]`, a Color `[r, g, b, a]`, a Quat `[x, y, z, w]`, nonzero and, for a field, of unit length, an Entity, Asset or Any null, an Enum one of `EnumValues`, an Array `[]`; a field is never Any); `Element` is an Array's element kind (not Array or Any; Number for other kinds), `AssetType` an Asset's type, `EnumValues` an Enum's 1 to 64 unique choices of 1 to 64 bytes (an Array of Asset or of Enum has them too); a field's `Options` are its Luau `FieldOptions` (Number, Integer, Bool, String, Vector, Color and Quat only): `Min`, `Max` and `Step` for Number, Integer and Vector (`Min <= Max`, `Step > 0`, the default within them) and a `Tooltip` of at most 256 bytes. A method (version 2) has at most 4 `Parameters` (a `Name` other than `self` and `Then`, unique in the method, a `Kind` but Enum and Array, and an Asset's optional `AssetType`) and at most one of `Results`; its `Method.<Name>` nodes run it and its `Return.<Name>` nodes end it. `RunsWhileWorldPaused` true lets the behaviour update while the world is paused. A version 1 file reads as version 2 without methods. The tables below list every field and the limits.

#### Fields of Graph

| Field | Type | Default | Range | Unit | Notes | Description |

| Field | Type | Default | Range | Unit | Notes | Description |

| Value | Description |
|---|---|

| `Integer` | An exact signed 32-bit integer (Field.Integer); Default an integer. |
| `Bool` | A boolean (Field.Bool); Default true or false. |

### Replay (`.replay`)

A recorded input replay (§6.7): the start scene and parameters, the seed and rate, the input events per tick, Luau expectations, the state-hash checkpoints the recording observed (one every 60 ticks before the final tick) and the final state hash. The state hash covers the simulated world: every entity with its serialized components, the tick, the session's Random state, the id draws and every body's physics state; it never covers script tables (self.State, module locals), audio or input, which expectations observe instead. Verification with strictHash compares each checkpoint as playback reaches it and stops at the first that differs. A recording with input events is refused when a run without them reproduces every checkpoint, the final hash and every expectation. Every recording also keeps its start fingerprint, what its session held at tick 0 (each entity and component, and each asset they reference), so a replay whose hash differs names what changed since it was recorded, and the locale its session started in, which every playback starts in. Older files are read as the current version (version 1 without checkpoints, versions 1 and 2 without a fingerprint, versions 1 to 3 with an empty SaveData, versions 1 to 4 with a null Locale), and project.upgrade rewrites them.

### SoundEffect (`.sfx`)

A procedural sound effect (§6.6): layers of oscillators synthesized into a 48 kHz mono clip. Each layer plays notes such as `"C#5:0.06"` (name with `#` or `b`, octave 0 to 8, seconds) and rests such as `"R:0.1"`, or one frequency sweep; the tables below list every field, its range and the limits.

Header: `"Format": "SoundEffect", "Version": 1`. Schema: [Schemas/SoundEffect.schema.json](Schemas/SoundEffect.schema.json).

```json
{
	"Format": "SoundEffect",
	"Version": 1,
	"Seed": 7,
	"Volume": 0.7,
	"Layers": [
		{
			"Wave": "Square",
			"DutyCycle": 0.5,
			"Notes": ["C5:0.06", "E5:0.06", "G5:0.06", "C6:0.18"],
			"Envelope": {
				"Attack": 0.005,
				"Decay": 0.05,
				"Sustain": 0.6,
				"Release": 0.08
			},
			"Volume": 0.6
		}
	]
}
```

#### Fields of SoundEffect

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Seed` | `UInt32` | `0` |  |  |  | The seed of the noise layers' generators. |
| `Volume` | `Float` | `1` | 0 to 1 |  |  | The sound's linear volume, from 0 to 1. |
| `Layers` | `Array<SoundLayer>` | `[]` |  |  |  | 1 to 16 layers, summed. A layer lasts its Delay, plus its notes' seconds (or its Duration), plus its Envelope's Release; the sound lasts as long as its longest layer, at most 10 seconds. |

#### Fields of SoundLayer

One oscillator of a sound effect: a note sequence (Notes) or, without notes, one tone sweeping from StartFrequency to EndFrequency over Duration. Every note, or the tone, plays with its own Envelope.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Wave` | `SoundWave` | `"Square"` |  |  |  | The oscillator's waveform. |
| `DutyCycle` | `Float` | `0.5` | 0.01 to 0.99 |  |  | Square waves only: the fraction of each period spent high. |
| `Notes` | `Array<String>` | `[]` |  |  |  | At most 256 notes played back to back, each "\<Name>\<Octave>:\<seconds>" such as "C5:0.06", or "R:\<seconds>" for a rest such as "R:0.1". Name is C, C#, Db, D, D#, Eb, E, F, F#, Gb, G, G#, Ab, A, A#, Bb or B (case-sensitive: '#' sharpens, 'b' flattens); Octave is one digit, 0 to 8, with A4 = 440 Hz in equal temperament and C4 middle C; seconds is a positive plain decimal (no exponent or sign) with at most 7 digits before and 8 after the point. Empty: the layer plays one tone of Duration seconds. |
| `Duration` | `Float` | `0.1` | 0 to 10 | s |  | Without notes: the sweep's length in seconds. |
| `StartFrequency` | `Float` | `440` | 20 to 20000 | Hz |  | Without notes: the sweep's first frequency. |
| `EndFrequency` | `Float` | `440` | 20 to 20000 | Hz |  | Without notes: the sweep's last frequency (an exponential glide). |
| `Volume` | `Float` | `1` | 0 to 1 |  |  | The layer's linear volume, from 0 to 1. |
| `Envelope` | `SoundEnvelope` | `{"Attack":0.005,"Decay":0,"Sustain":1,"Release":0.01}` |  |  |  | The volume envelope of each note. |
| `LowPass` | `Float` | `0` | 0 to 20000 | Hz |  | The cutoff of a one-pole low-pass filter in Hz; 0 leaves the layer unfiltered. |
| `Delay` | `Float` | `0` | 0 to 10 | s |  | Seconds from the sound's start until the layer starts. |

#### Fields of SoundEnvelope

The ADSR volume envelope every note of a layer plays with.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Attack` | `Float` | `0.005` | 0 to 10 | s |  | Seconds from silence to full level at the note's start. |
| `Decay` | `Float` | `0` | 0 to 10 | s |  | Seconds from full level down to the sustain level. |
| `Sustain` | `Float` | `1` | 0 to 1 |  |  | The level held until the note ends, from 0 to 1. |
| `Release` | `Float` | `0.01` | 0 to 10 | s |  | Seconds from the sustain level to silence after the note ends. |

#### Values of SoundWave

The oscillator of a sound effect layer.

| Value | Description |
|---|---|
| `Sine` | A pure sine tone. |
| `Square` | A square wave with an adjustable duty cycle: hollow, chiptune-like. |
| `Triangle` | A triangle wave: soft, flute-like. |
| `Saw` | A sawtooth wave: bright and buzzy. |
| `Noise` | Seeded noise, resampled at the frequency: hiss, hits and explosions. |

### SpriteSheet (`.spritesheet`)

A null `Texture` draws the frames as opaque white. The tables below list every field, its range and the limits.

#### Fields of SpriteSheet

| Field | Type | Default | Range | Unit | Notes | Description |

#### Fields of SpriteFrame

One frame of a sprite sheet: a rectangle of its texture with a pivot and 9-slice borders. Clips and sprites refer to it by its index.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Name` | `String` | `""` |  |  |  | An optional label of at most 128 bytes, without control characters, unique among the frames when not empty. |

| `Pivot` | `Vec2` | `[0.5,0.5]` | 0 to 1 |  |  | The point of the frame placed at its sprite's position, as a fraction of the frame's size from its top-left corner: (0.5, 0.5) is its centre, (0.5, 1) the middle of its bottom edge. |
| `Borders` | `SpriteBorders` | `{"Left":0,"Top":0,"Right":0,"Bottom":0}` |  |  |  | The frame's 9-slice insets. |

#### Fields of SpriteRect

A frame's rectangle in its texture, in whole texels: x right and y down from the texture's top-left corner.

| Field | Type | Default | Range | Unit | Notes | Description |

| `Width` | `UInt32` | `1` | 1 to 16384 | texels |  | The frame's width; X + Width is at most 16384. |
| `Height` | `UInt32` | `1` | 1 to 16384 | texels |  | The frame's height; Y + Height is at most 16384. |

#### Fields of SpriteBorders

| Field | Type | Default | Range | Unit | Notes | Description |

| Field | Type | Default | Range | Unit | Notes | Description |

#### Fields of SpriteClipFrame

| Field | Type | Default | Range | Unit | Notes | Description |

### StringTable (`.stringtable`)

A string table (§6.10): locale tags, the first of them the fallback, and entries that give each key a string per locale, read by `Loc.Get` in the project's `Localization.Locale` (the table's locale equal to it ignoring ASCII case, else its language's, the part before its first `-`, else the fallback; an entry without a string for that locale gives the fallback's). Lookups are byte-wise and deterministic. The tables below list every field, its rules and the limits.

Header: `"Format": "StringTable", "Version": 1`. Schema: [Schemas/StringTable.schema.json](Schemas/StringTable.schema.json).

```json
{
	"Format": "StringTable",
	"Version": 1,
	"Locales": ["en", "fr", "pt-BR"],
	"Entries": [
		{
			"Key": "Menu.Start",
			"Values": {
				"en": "Start",
				"fr": "Commencer",
				"pt-BR": "Iniciar"
			}
		},
		{
			"Key": "Menu.Quit",
			"Values": {
				"en": "Quit"
			}
		}
	]
}
```

#### Fields of StringTable

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Locales` | `Array<String>` | `["en"]` |  |  |  | 1 to 64 locale tags (1 to 35 ASCII letters, digits and '-', starting with a letter, such as en, fr or pt-BR), unique ignoring ASCII case; the first is the fallback locale. |
| `Entries` | `Array<StringTableEntry>` | `[]` |  |  |  | At most 65536 entries, in authored order (sorted by Key once cooked). |

#### Fields of StringTableEntry

One key and its strings by locale.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Key` | `String` | `""` |  |  |  | The entry's identity, which Loc.Get looks up: 1 to 256 bytes of text without control characters, unique in the table. |
| `Values` | `Map<String>` | `{}` |  |  |  | The entry's strings by locale (each key one of the table's Locales, written sorted): at most 16384 bytes of UTF-8 each, line feeds and tabs their only control characters; the fallback locale's string is required, the others optional. |

### Tilemap (`.tilemap`)

A tilemap (§6.9): a palette of sprite sheet frames, each Solid or not for the TilemapCollider, and cells in chunks of `ChunkSize` x `ChunkSize` (a power of two), sorted by (Y, X), none empty. Cell (x, y), x right and y up in the entity's local plane, spans `[x CellSize.x, (x + 1) CellSize.x]` in X; chunk (X, Y) holds the cells from (X ChunkSize, Y ChunkSize), its `Tiles` row by row from its bottom row up, each 0 for empty or k for `Palette[k - 1]`. The tables below list every field, its range and the limits.

Header: `"Format": "Tilemap", "Version": 1`. Schema: [Schemas/Tilemap.schema.json](Schemas/Tilemap.schema.json).

```json
{
	"Format": "Tilemap",
	"Version": 1,
	"CellSize": [1, 1],
	"ChunkSize": 2,
	"Palette": [
		{
			"Sheet": "5b5e000000000002",
			"Frame": 0,
			"Solid": true
		},
		{
			"Sheet": "5b5e000000000003",
			"Frame": 4,
			"Solid": false
		}
	],
	"Chunks": [
		{
			"X": -1,
			"Y": 0,
			"Tiles": [0, 1, 0, 0]
		},
		{
			"X": 0,
			"Y": 0,
			"Tiles": [1, 1, 2, 0]
		}
	]
}
```

#### Fields of Tilemap

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `CellSize` | `Vec2` | `[1,1]` | 0.001 to 1000 | units |  | The size of a cell in the entity's local units: cell (x, y) spans [x CellSize.x, (x + 1) CellSize.x] in X. |
| `ChunkSize` | `UInt32` | `16` | 1 to 64 |  |  | The cells a chunk holds a side: a power of two from 1 to 64 (16 by default). |
| `Palette` | `Array<TilemapTile>` | `[]` |  |  |  | At most 65535 entries; a cell value k draws Palette[k - 1]. |
| `Chunks` | `Array<TilemapChunk>` | `[]` |  |  |  | The stored chunks, sorted by Y, then X, each once, none empty; at most 4194304 cells in all. |

#### Fields of TilemapTile

One entry of a tilemap's palette: the sprite sheet frame drawn in the cells holding it, and whether the TilemapCollider collides with them.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Sheet` | `AssetRef(SpriteSheet)` | `null` |  |  |  | The sprite sheet the tile is cut from; null draws nothing. |
| `Frame` | `UInt32` | `0` | 0 to 65535 |  |  | The index of the frame in the sheet's Frames, from 0; a frame the sheet lacks draws nothing (TILEMAP_FRAME_OUT_OF_RANGE). |
| `Solid` | `Bool` | `true` |  |  |  | Whether the TilemapCollider collides with the cells holding this entry. |

#### Fields of TilemapChunk

A square of ChunkSize x ChunkSize cells of a tilemap, stored while one of them is not empty; chunk (X, Y) holds the cells from (X ChunkSize, Y ChunkSize).

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `X` | `Int32` | `0` |  |  |  | The chunk's column: its cells' x lie in [X ChunkSize, (X + 1) ChunkSize), and in [-1048576, 1048576). |
| `Y` | `Int32` | `0` |  |  |  | The chunk's row: its cells' y lie in [Y ChunkSize, (Y + 1) ChunkSize), and in [-1048576, 1048576). |
| `Tiles` | `Array<UInt32>` | `[]` |  |  |  | The ChunkSize^2 cell values, row by row from the chunk's bottom row up, each row left to right: 0 for an empty cell, k for Palette[k - 1]; not all 0. |
