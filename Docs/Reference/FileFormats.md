# File formats

Generated by `Editor --dump-reference` and written by `python Scripts/GenerateDocs.py`; do not edit by hand.

Every authored file is UTF-8 JSON with LF line ends and tabs, written by the canonical writer: `Format` and `Version` first, keys in registry order, PascalCase keys, floats in their shortest round-trip form and default values written out (Architecture §6). Unknown fields warn and unknown components are preserved verbatim; `--strict` makes both errors. A newer `Version` than the reader supports fails with `UnsupportedVersion`. Each format has a JSON Schema (draft 2020-12, the subset the engine's validator supports) in `Schemas/`.

### AssetMeta (`.meta`)

The sidecar of every asset file (§6.4): its handle, type, importer, import settings and sub-assets; or, for a file a glTF references, a dependency meta naming its owner.

Header: `"Format": "AssetMeta", "Version": 1`. Schema: [Schemas/AssetMeta.schema.json](Schemas/AssetMeta.schema.json).

```json
{
	"Format": "AssetMeta",
	"Version": 1,
	"Handle": "8c5e9fa7d7637795",
	"Type": "Texture",
	"Importer": "Texture",
	"ImporterVersion": 1,
	"Settings": {
		"Usage": "Color",
		"GenerateMips": true
	},
	"SubAssets": []
}
```

### BatchRequest (`.jsonl`)

One line of an automation batch file (§6.7): `{"method", "params"}`; `{"$ref": "<line>.<jsonPath>"}` inside params references an earlier result. Lines have no Format header.

Schema: [Schemas/BatchRequest.schema.json](Schemas/BatchRequest.schema.json).

```json
{"method":"entity.create","params":{"name":"Ball","components":{"Transform":{"Translation":[0,2,0]}}}}
```

### GameManifest (`Game.json`)

The exported game's manifest next to its executable (§14.1): name, engine version, start scene, paks, window and simulation settings.

Header: `"Format": "GameManifest", "Version": 1`. Schema: [Schemas/GameManifest.schema.json](Schemas/GameManifest.schema.json).

```json
{
	"Format": "GameManifest",
	"Version": 1,
	"Name": "Tetris",
	"EngineVersion": "0.1.0",
	"StartScene": "8a61c0d2e4f31b77",
	"Paks": [
		{
			"Path": "Data/Engine.pak",
			"XXH64": "0123456789abcdef"
		},
		{
			"Path": "Data/Game.pak",
			"XXH64": "fedcba9876543210"
		}
	],
	"Window": {
		"Title": "Tetris",
		"Width": 720,
		"Height": 900,
		"VSync": true,
		"Fullscreen": false,
		"Resizable": true
	},
	"Simulation": {
		"FixedHz": 60,
		"MaxStepsPerFrame": 5,
		"Seed": 1,
		"MaxEntities": 65536
	},
	"Testing": false
}
```

	"Format": "Prefab",
	"Version": 1,

### Provenance (`Automation/Provenance.json`)

Which automation request wrote each engine-consumed file of a project (§13.4), sorted by Path.

Header: `"Format": "Provenance", "Version": 1`. Schema: [Schemas/Provenance.schema.json](Schemas/Provenance.schema.json).

```json
{
	"Format": "Provenance",
	"Version": 1,
	"Entries": [
		{
			"Path": "Assets/Scenes/Main.scene",
			"XXH64": "0f1e2d3c4b5a6978",
			"Method": "scene.save",
			"RequestId": 17,
			"Client": "engine-mcp",
			"TranscriptLine": 42
		}
	]
}
```

### Replay (`.replay`)

A recorded input replay (§6.7): the start scene and parameters, the seed and rate, the input events per tick, Luau expectations and the final state hash.

Header: `"Format": "Replay", "Version": 1`. Schema: [Schemas/Replay.schema.json](Schemas/Replay.schema.json).

```json
{
	"Format": "Replay",
	"Version": 1,
	"Scene": {
		"Handle": "8a61c0d2e4f31b77",
		"Path": "Assets/Scenes/Level2.scene"
	},
	"Parameters": {
		"Time": 61.25
	},
	"Seed": 7,
	"FixedHz": 60,
	"EngineVersion": "0.1.0",
	"Config": "Editor",
	"Events": [
		{
			"Tick": 0,
			"Type": "Action",
			"Name": "MoveZ",
			"Value": 1
		},
		{
			"Tick": 310,
			"Type": "Action",
			"Name": "Jump",
			"State": "Tap"
		},
		{
			"Tick": 320,
			"Type": "Key",
			"Key": "Escape",
			"State": "Down"
		},
		{
			"Tick": 321,
			"Type": "Key",
			"Key": "Escape",
			"State": "Up"
		}
	],
	"Expect": [
		{
			"Tick": 900,
			"Luau": "return Scene.GetName() == 'Level3'"
		}
	],
	"FinalTick": 900,
	"FinalStateHash": "3e0c91a2b4d5f607"
}
```

### Scene (`.scene`)

A scene (§6.2): entities in canonical order with their components keyed by registry name.

Header: `"Format": "Scene", "Version": 1`. Schema: [Schemas/Scene.schema.json](Schemas/Scene.schema.json).

```json
{
	"Format": "Scene",
	"Version": 1,
	"Name": "Level1",
	"Seed": 42,
	"ComponentVersions": {
		"Transform": 1,
		"Camera": 1
	},
	"Entities": [
		{
			"ID": "5d1c9a7e33b04f12",
			"Name": "Camera",
			"Parent": null,
			"Active": true,
			"Tags": ["MainCamera"],
			"Components": {
				"Transform": {
					"Translation": [0, 2, -10],
					"Rotation": [0, 0, 0, 1],
					"Scale": [1, 1, 1]
				},
				"Camera": {
					"Primary": true
				}
			}
		}
	]
}
```

### SoundEffect (`.sfx`)

A procedural sound effect (§6.6): layers of oscillators synthesized into a 48 kHz mono clip.

Header: `"Format": "SoundEffect", "Version": 1`. Schema: [Schemas/SoundEffect.schema.json](Schemas/SoundEffect.schema.json).

```json
{
	"Format": "SoundEffect",
	"Version": 1,
	"Seed": 7,
	"Volume": 0.7,
	"Layers": [
		{
			"Wave": "Square",
			"DutyCycle": 0.5,
			"Notes": ["C5:0.06", "E5:0.06", "G5:0.06", "C6:0.18"],
			"Envelope": {
				"Attack": 0.005,
				"Decay": 0.05,
				"Sustain": 0.6,
				"Release": 0.08
			},
			"Volume": 0.6
		}
	]
}
```

## Source formats
