# File formats

Generated by `Editor --dump-reference` and written by `python Scripts/GenerateDocs.py`; do not edit by hand.

Every authored file is UTF-8 JSON with LF line ends and tabs, written by the canonical writer: `Format` and `Version` first, keys in registry order, PascalCase keys, floats in their shortest round-trip form and default values written out (Architecture §6). Unknown fields warn; unknown components warn and are preserved on save, their numbers written as floats like every authored number, and one holding a fractional number outside the float range, which could not be written back, is `SCENE_INVALID_COMPONENT` (an error in a strict load, dropped by a repair load). `Editor --strict` makes unknown keys, fields and components errors and refuses a project any of whose scenes and prefabs does not load strictly. A newer `Version` than the reader supports fails with `UnsupportedVersion`. Each format has a JSON Schema (draft 2020-12, the subset the engine's validator supports) in `Schemas/`.

### AssetMeta (`.meta`)

The sidecar of every asset file (§6.4): its handle, type, importer, import settings and sub-assets; or, for a file a glTF references, a dependency meta naming its owner.

Header: `"Format": "AssetMeta", "Version": 1`. Schema: [Schemas/AssetMeta.schema.json](Schemas/AssetMeta.schema.json).

```json
{
	"Format": "AssetMeta",
	"Version": 1,
	"Handle": "8c5e9fa7d7637795",
	"Type": "Texture",
	"Importer": "Texture",
	"ImporterVersion": 1,
	"Settings": {
		"Usage": "Color",
		"GenerateMips": true
	},
	"SubAssets": []
}
```

### BatchRequest (`.jsonl`)

One line of an automation batch file (§6.7): `{"method", "params"}`; `{"$ref": "<line>.<jsonPath>"}` inside params references an earlier result. Lines have no Format header.

Schema: [Schemas/BatchRequest.schema.json](Schemas/BatchRequest.schema.json).

```json
{"method":"entity.create","params":{"name":"Ball","components":{"Transform":{"Translation":[0,2,0]}}}}
```

### Replay (`.replay`)

A recorded input replay (§6.7): the start scene and parameters, the seed and rate, the input events per tick, Luau expectations, the state-hash checkpoints the recording observed (one every 60 ticks before the final tick) and the final state hash. The state hash covers the simulated world: every entity with its serialized components, the tick, the session's Random state, the id draws and every body's physics state; it never covers script tables (self.State, module locals), audio or input, which expectations observe instead. Verification with strictHash compares each checkpoint as playback reaches it and stops at the first that differs. A recording with input events is refused when a run without them reproduces every checkpoint, the final hash and every expectation. Every recording also keeps its start fingerprint, what its session held at tick 0 (each entity and component, and each asset they reference), so a replay whose hash differs names what changed since it was recorded. Version 1 files (no checkpoints) and version 2 files are read as version 3 with no fingerprint, and project.upgrade rewrites them.

### SoundEffect (`.sfx`)

A procedural sound effect (§6.6): layers of oscillators synthesized into a 48 kHz mono clip. Each layer plays notes such as `"C#5:0.06"` (name with `#` or `b`, octave 0 to 8, seconds) and rests such as `"R:0.1"`, or one frequency sweep; the tables below list every field, its range and the limits.

Header: `"Format": "SoundEffect", "Version": 1`. Schema: [Schemas/SoundEffect.schema.json](Schemas/SoundEffect.schema.json).

```json
{
	"Format": "SoundEffect",
	"Version": 1,
	"Seed": 7,
	"Volume": 0.7,
	"Layers": [
		{
			"Wave": "Square",
			"DutyCycle": 0.5,
			"Notes": ["C5:0.06", "E5:0.06", "G5:0.06", "C6:0.18"],
			"Envelope": {
				"Attack": 0.005,
				"Decay": 0.05,
				"Sustain": 0.6,
				"Release": 0.08
			},
			"Volume": 0.6
		}
	]
}
```

#### Fields of SoundEffect

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Seed` | `UInt32` | `0` |  |  |  | The seed of the noise layers' generators. |
| `Volume` | `Float` | `1` | 0 to 1 |  |  | The sound's linear volume, from 0 to 1. |
| `Layers` | `Array<SoundLayer>` | `[]` |  |  |  | 1 to 16 layers, summed. A layer lasts its Delay, plus its notes' seconds (or its Duration), plus its Envelope's Release; the sound lasts as long as its longest layer, at most 10 seconds. |

#### Fields of SoundLayer

One oscillator of a sound effect: a note sequence (Notes) or, without notes, one tone sweeping from StartFrequency to EndFrequency over Duration. Every note, or the tone, plays with its own Envelope.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Wave` | `SoundWave` | `"Square"` |  |  |  | The oscillator's waveform. |
| `DutyCycle` | `Float` | `0.5` | 0.01 to 0.99 |  |  | Square waves only: the fraction of each period spent high. |
| `Notes` | `Array<String>` | `[]` |  |  |  | At most 256 notes played back to back, each "\<Name>\<Octave>:\<seconds>" such as "C5:0.06", or "R:\<seconds>" for a rest such as "R:0.1". Name is C, C#, Db, D, D#, Eb, E, F, F#, Gb, G, G#, Ab, A, A#, Bb or B (case-sensitive: '#' sharpens, 'b' flattens); Octave is one digit, 0 to 8, with A4 = 440 Hz in equal temperament and C4 middle C; seconds is a positive plain decimal (no exponent or sign) with at most 7 digits before and 8 after the point. Empty: the layer plays one tone of Duration seconds. |
| `Duration` | `Float` | `0.1` | 0 to 10 | s |  | Without notes: the sweep's length in seconds. |
| `StartFrequency` | `Float` | `440` | 20 to 20000 | Hz |  | Without notes: the sweep's first frequency. |
| `EndFrequency` | `Float` | `440` | 20 to 20000 | Hz |  | Without notes: the sweep's last frequency (an exponential glide). |
| `Volume` | `Float` | `1` | 0 to 1 |  |  | The layer's linear volume, from 0 to 1. |
| `Envelope` | `SoundEnvelope` | `{"Attack":0.005,"Decay":0,"Sustain":1,"Release":0.01}` |  |  |  | The volume envelope of each note. |
| `LowPass` | `Float` | `0` | 0 to 20000 | Hz |  | The cutoff of a one-pole low-pass filter in Hz; 0 leaves the layer unfiltered. |
| `Delay` | `Float` | `0` | 0 to 10 | s |  | Seconds from the sound's start until the layer starts. |

#### Fields of SoundEnvelope

The ADSR volume envelope every note of a layer plays with.

| Field | Type | Default | Range | Unit | Notes | Description |
|---|---|---|---|---|---|---|
| `Attack` | `Float` | `0.005` | 0 to 10 | s |  | Seconds from silence to full level at the note's start. |
| `Decay` | `Float` | `0` | 0 to 10 | s |  | Seconds from full level down to the sustain level. |
| `Sustain` | `Float` | `1` | 0 to 1 |  |  | The level held until the note ends, from 0 to 1. |
| `Release` | `Float` | `0.01` | 0 to 10 | s |  | Seconds from the sustain level to silence after the note ends. |

#### Values of SoundWave

The oscillator of a sound effect layer.

| Value | Description |
|---|---|
| `Sine` | A pure sine tone. |
| `Square` | A square wave with an adjustable duty cycle: hollow, chiptune-like. |
| `Triangle` | A triangle wave: soft, flute-like. |
| `Saw` | A sawtooth wave: bright and buzzy. |
| `Noise` | Seeded noise, resampled at the frequency: hiss, hits and explosions. |
