## Context

Each fact below was read in the code at `7bfd889d`.

- **A graph is a Script asset.** `GraphImporter` (`AssetPipeline/Importers/GraphImporter.h`, id `"Graph"`, `Version` 1) reads the document strictly (`GraphFromText`), validates it against a `GraphNodeLibrary` built from the import's pure script API, transpiles it (`TranspileGraph`) and extracts the text through the load-time VM under the `.graph` path. The format is `GraphFormatVersion` 1 (`GraphDocument.h`): `Name`, `Fields`, `Variables`, `Nodes`, `Links`, read through the type registry's `"Graph"` struct, whose `ReadGraphDocument` accepts versions 1 to 1 (`ReadFormatHeader`). `project.upgrade` reads every `.graph` through `GraphFromText` and writes `GraphToText`'s canonical text when it differs (`ProjectMethods.cpp`'s `.graph` case), so a format bump needs no change there (ADR 0035 decision 10).
- **The node library** (`GraphNodeLibrary.cpp`): generated `Event.<Callback>`, `Call.*`, `Get.*`, `Set.*`, `Const.*` kinds from the frozen script API, and the built-ins of `MakeBuiltinNodes` (`Flow.*`, `Self.Entity`, the operators); `Self.Get.<Name>` and `Self.Set.<Name>` are graph-dependent (`GetMemberNodes`, `Resolve`) and outside `GetNodes` and the fingerprint. `MakeEventNode` reads a callback's parameters and ignores its results; the eight `OnUi*` callbacks are declared `-> boolean?` (`Bindings/Script.cpp`) and are the only Behaviour callbacks with a result. `GetMemberPinType` maps a member's kind to a pin type (Integer as Number, Enum as String, Array as Any). A node's category is `GraphNodeCategory` (Event, Flow, Member, Operator, Call, Property, Constant); the analysis treats an Event-category node as a flow's start and a non-pure node of another category as a statement.
- **Only engine values have members a graph can reach.** `Call.Entity.GetScript` is `(self: Entity, name: string?) -> any` (`Bindings/Entity.cpp`), a pure node whose `Result` is Any; `Get.ScriptInstance.Entity` is the only instance member a graph reads. A behaviour instance's metatable is its class with `__index` set to it (`ScriptInstances.cpp`), so `entity:GetScript("Lever"):Pull()` finds `Graph.Pull` once the transpiler writes it. A missing key of a table reads nil; a missing member of an engine value raises "unknown `<Type>` member" from the registry's `__index`.
- **The transpiler** (`GraphTranspiler.cpp`): `--!strict`, the header comment, `local Graph = {}`, `Graph.Fields`, `function Graph.OnCreate(self: any)`, one function per other callback with event nodes in byte-wise order, `return Script.Define(...)`. A statement's code is `-- <Id>: <Kind>` then, when it reads pure values or binds an object that starts with `(`, a `do ... end` block; a statement entered by several exec links is a merge, laid out as `local function flow<Id>()` at the top of the event function (after the `local n<Id>_<Pin>: <type>` declarations) and called `flow<Id>()` at each entry; an event's data outputs are the function's parameters by their pin names; `GetArguments` passes a call's data inputs but `self` in pin order, trailing unset optional ones left out. `FindGraphTextLimitIssues` lays the text out as `TranspileGraph` does, so its depth (64 blocks) and size (8 MiB) limits measure every line the transpiler writes.
- **The strict checker runs Luau's lints.** `ScriptTypeChecker` sets `runLintChecks`, and `LintOptions::setDefaults` enables every warning (`Vendor/Luau/Config/src/LinterConfig.cpp`), so a statement after one that always returns gets `UnreachableCode` (`Linter.cpp`: a block's status is its first statement that always returns; an `if` returns only when both branches do), reported as a Warning finding. A line that starts with `(` after a call is Luau's ambiguous-syntax error, which is why the transpiler binds such an object to a local first.
- **The world pause's opt-in** is a class key: `Script.Define` reads `RunsWhileWorldPaused` (a boolean or nil, anything else an error) from the class table before registering it (`Bindings/Script.cpp`); the transpiled class never sets it (`Docs/Backlog.md` §6). `IsReservedScriptFieldName` (`Asset/ScriptData.cpp`) holds `Entity`, `Fields`, the callbacks and every `__` name, but not `RunsWhileWorldPaused`.
- **Live values.** Every pure and statement output is written to `self.__GraphLive["<Id>.<Pin>"]`; event outputs (parameters) are not; `ReadInstanceValues` returns a table, function or proxy as null with its type name.
- **The type registry has no optional field.** `Detail::DeduceFieldType` (`Reflection/TypeInfo.h`) reflects scalars, strings, UUIDs, Variants, asset handles, enums, vectors, string maps and structs; a `std::optional` member is not reflectable, so ADR 0052's `Result: {Kind, AssetType} | null` cannot be a registry member as written.
- **The compact tool schema budget.** `Tools/MCP/tests/test_schemas.py` requires every proxied tool's compact input schema to stay below `MAX_SCHEMA_BYTES` (4,096 bytes); `graph_set_members`' is 3,384 bytes in `Tools/MCP/catalog.json`, its fields and variables inlined (`MethodRegistry.cpp`'s `InlineDefinitions`). An inlined method list with two `GraphValueKind` enums measures about 1,360 bytes even with terse descriptions.
- **Graphs in the projects.** FeatureTest holds four graphs (`Assets/Scripts/Graphs/`), Rolling Ball one (`Assets/Scripts/Checkpoint.graph`, version 1), the tests' fixtures four (`Tests/Data/Graphs/{Bumper,Counter,Door,Mover}.graph` with their `.luau` texts), the validation fixtures two (`GRAPH_INVALID/.../Broken.graph`, `GRAPH_UNREACHABLE_NODE/.../Stray.graph`, written by `MakeValidationFixtures.py` at version 1). The `GraphDocument` fuzz case seeds from Door's text.

## Decisions

### 1. Graph format 2 (W39.1)

- **Version.** `GraphFormatVersion` 2. `GraphFromJson` reads versions 1 and 2 and returns the version 2 document. A version 1 file reads as version 2 with no methods and `RunsWhileWorldPaused` false; in a version 1 file `Methods` and `RunsWhileWorldPaused` are unknown members (a `REFLECTION_UNKNOWN_FIELD` warning that drops them, or with `strictUnknowns` a located Validation error, as every unknown member), and a variable of kind `Any` is a located Validation error at its `Kind`, since no version 1 engine wrote one. A newer file stays `UnsupportedVersion`, so an older engine refuses version 2. `project.upgrade` rewrites a version 1 file as its version 2 canonical text through its existing `.graph` case.
- **The document** (registry struct `"Graph"`, members in this order, every one written): `Name`, `RunsWhileWorldPaused` (bool, false), `Fields`, `Variables`, `Methods`, `Nodes`, `Links`.
- **`GraphValueKind::Any`**, appended after `Array` ("Any value: a variable, a method's parameter or result; never a field"). Valid as a variable's, a parameter's and a result's kind; refused as a field's `Kind` (no `Field` constructor holds any value) and as any member's `Element`. A variable of kind Any has the `Default` null, `OnCreate` sets it to nil, and its `Self.Get` and `Self.Set` pins are Any.
- **Methods** (registry struct `"GraphMethod"`): `Name` (string), `Parameters` (list of `"GraphParameter"`: `Name`, `Kind`, `AssetType`), `Results` (list of `"GraphResult"`: `Kind`, `AssetType`; empty for a method without a result, at most one; departure 2). Rules, each a located issue of `ValidateGraphStructure`:
  - at most `MaxGraphMethods` (64) methods, sorted by `Name` byte-wise;
  - a method's `Name` is an `IsGraphIdentifier`, not `IsReservedScriptFieldName` (as it stands on the tree: M37's and M38's callbacks join it at their landing), not `RunsWhileWorldPaused` (`Script.Define` refuses that key as anything but a boolean), and unique across the fields, the variables and the methods;
  - at most `MaxGraphMethodParameters` (4) parameters, matching `Script.Call`'s four arguments; a parameter's `Name` is an `IsGraphIdentifier` other than `self` (the instance) and `Then` (the exec output of its `Method.<Name>` node, whose data outputs are the parameters), unique in its method;
  - at most `MaxGraphMethodResults` (1) result; a second one is refused at `/Methods/<i>/Results/1`;
  - a parameter's or result's `Kind` is Number, Integer, Bool, String, Vector, Color, Quat, Entity, Asset or Any: not Enum, which would need choices the declaration does not carry (a String carries a choice), and not Array (an Any carries a table); its `AssetType` is empty, or for an Asset an AssetType name other than None (empty: any asset).
- **Limits and canonical order** as M24's: the methods sorted by name join `CanonicalizeGraph`; the registry's Generate hook repairs random methods (names, kinds, counts, order) so the registry suite's random graphs stay valid.
- **Fixtures:** `Tests/Data/Formats/Graph/v1.graph` (a version 1 graph with fields, a variable and nodes) and its `v1.upgraded.graph` (the version 2 text `project.upgrade` writes); `Tests/Data/Graphs/` rewritten at version 2 (their `.luau` texts unchanged) with two new fixture graphs of their own, `Rune.graph` and `Valve.graph`, and their texts (decision 4). The `GRAPH_*` validation fixtures stay at version 1, which reads as version 2, so `MakeValidationFixtures.py` (shared with M36 to M38) does not change. FeatureTest's four graphs are rewritten at version 2 by `Scaffold.py`, which writes their provenance entries with them (the reference generator's test validates every authored file against its schema, whose `Version` is now 2); W39.1's checkpoint had rewritten them by hand, leaving `Automation/Provenance.json` stale (the review of W39.1, finding 1), and the regeneration that W39.2's scaffolds need replaced that edit, so no hand edit remains.

### 2. Members of any value (W39.1)

Four built-ins in category `Member`, whose registry description widens to "this or another behaviour's members":

| Kind | Pure | Pins | Text |
|---|---|---|---|
| `Script.Get` | yes | `Object` Any (required), `Member` String (default `""`) → `Value` Any | `local v<Id>_Value: any = (<object> :: any)[<member>]` |
| `Script.Set` | no | `In`; `Object` Any (required), `Member` String, `Value` Any (required) → `Then` | a block: `local o<Id>: any = <object>`, then `o<Id>[<member>] = <value>` |
| `Script.Call` | no | `In`; `Object` Any (required), `Method` String, `Arg1` to `Arg4` Any (optional) → `Then`, `Result` Any | a block: `local o<Id>: any = <object>`, then `n<Id>_Result = (o<Id>:<Method>(<args>) :: any)` when `Method` is an unlinked literal that `IsGraphIdentifier` accepts (a Luau name of 1 to 64 bytes, not a reserved word, not starting with `__`, as a member's; the review of W39.1 dropped the transpiler's own keyword list), else `n<Id>_Result = (o<Id>[<method>](o<Id>, <args>) :: any)` |
| `Self.Instance` | yes | → `Value` Any | `local v<Id>_Value: any = self` |

- `Script.Set` and `Script.Call` bind their object to the local `o<Id>` (typed `any`), so no line starts with `(` and the strict checker accepts every member; `Script.Get` is an expression and casts in place. A required Any input must be linked or hold a literal (Incomplete otherwise, as M24's rule); so a `Script.Set` that writes nil links a value that is nil.
- `Script.Call`'s arguments are `Arg1` to `Arg4` in order, trailing unset ones left out (an unset one between set ones passes nil); its `Result` is the first result only, cast `:: any`.
- **Run time** is Luau's: a missing member of a table reads nil (for `Flow.IfNotNil`); indexing nil, a missing member of an engine value, or calling nil or a missing method raises Luau's error at the node's line, which `LineNodes` maps to the node (`graph.read`, `graph.liveValues`, the Diagnostics panel).
- `Self.Instance` passes the graph's own instance (`Health:Register(self)`) or calls its own methods through `Script.Call`; `Self.Call.<Name>` stays out (ADR 0052).

### 3. Graph methods (W39.1)

- **Kinds, graph-dependent like `Self.*`** (`GetMemberNodes`, `Resolve`; not in `GetNodes` or the fingerprint): `Method.<Name>` (category Event, title "Method <Name>"): a `Then` exec output and one data output per parameter, named by the parameter and typed by its kind (`GetMemberPinType`, Any for Any; an Asset's `TypeName` its AssetType), never optional; several `Method.<Name>` nodes run in id order, as a callback's do. `Return.<Name>` (category Flow, title "Return <Name>"): a statement with `In` and no exec output, and a `Value` input typed by the result (required, with the pin type's default where it has one: Number 0, Bool false, ...; optional for an Any result, unset returning nil), absent for a method without a result.
- **`GetMemberNodes`** returns every graph-dependent kind: `Self.Get` and `Self.Set` of the fields and variables and `Method` and `Return` of the methods, sorted by kind.
- **The text:** one `function Graph.<Name>(self: any, p_<param>: <type>, ...)` per method, in name order, after the callbacks' functions and before `return Script.Define`. Each parameter is the local `p_<Name>` (departure 3), typed by its pin (`number`, `boolean`, `string`, `vector`, `Color`, `Quat`, `Entity`, `AssetRef`, `any`), and a `Method.<Name>` node's output reads it. A declared method without an event node is an empty function (`return nil` in it when it declares a result, decision 4).
- **Callers:** a Luau behaviour or another graph calls the method on the instance (`entity:GetScript("Rune"):Damaged(hit)`, or `Script.Call` with `Method` `"Damaged"`); the method runs in its caller's callback and phase, under its caller's deadline, and returns its result. A method name is a string at its callers, so `graph.setMembers`' rename rewrites the graph's own `Method` and `Return` nodes only (decision 8).

### 4. Returns (W39.1)

- **`Return.<Callback>`** for every Behaviour callback whose signature has a result (`ParseLuauFunction`'s results: the eight `OnUi*` today), in `GetNodes` (graph-independent; category Flow): `In`, no exec output, and a `Value` input of the result's type (`boolean?`: an optional Bool), so nil (unset) lets the UI event bubble on and true consumes it. This closes `Docs/Backlog.md` §6's "a graph's UI event never consumes the event".
- **Where a `Return` runs it ends its function, Luau's own `return`:** later statements of its flow and later event nodes of its function do not run. Its code is always a `do ... end` block of its own (so `return` is the last statement of a block wherever the flow puts it, a `Flow.Sequence`'s first output or an event before another included): `return <value>` for a method with a result or a callback's `Return`, `return` for a method without one. A `Return` entered by several exec links is a merge as any other statement is (the review of W39.1): its flow function `local function flow<Id>(): boolean` sets `result` (with a value) and returns true, each entry is `if flow<Id>() then return result end`, and since its body always returns it ends with no `return false`.
- **Through a merge:** a merge whose flow reaches a `Return` (through any statements and merges, the `Later` flows aside, which the validation refuses) is `local function flow<Id>(): boolean`; inside it a `Return` is `result = <value>` then `return true` (or `return true` alone without a value), and the function ends with `return false` unless its body always returns. Each call of such a merge is `if flow<Id>() then return result end` in the event function (`return` without a value), and `if flow<Id>() then return true end` inside another flow function. A function whose merges reach a valued `Return` declares `local result: any` after its statements' locals. A merge whose flow reaches no `Return` keeps M24's text.
- **Every path returns one value:** a function that returns a value (a method with a result, or a callback's function with a `Return.<Callback>` node) ends with `return nil` unless its body always returns, judged as Luau's `UnreachableCode` lint judges it (a block returns when one of its statements does; an `if` when both branches do; a loop, a `Flow.Delay` and a merge's call never), so the text never adds an unreachable line of its own. Statements a graph places after a `Return` (a `Flow.Sequence`'s later outputs) stay in the text, where the lint's warning names their node, as Luau would.
- **Byte identity:** a graph without methods, `Return` nodes or the opt-in transpiles to exactly M24's text, which the fixture texts and FeatureTest's graphs check (`GraphImporter::Version` stays 1, decision 9).

### 5. Validation (W39.1)

`ValidateGraph`'s new rules, each a `GRAPH_INVALID` issue that is not Incomplete (so refused by every edit), located at the node (`/Nodes/<i>`):
- a `Method.<Name>` or `Return.<Name>` kind names a declared method, and a `Return.<Callback>` a callback with a result: an unknown kind otherwise (M24's issue, with its suggestions);
- a `Return` is reached only from its own function's event nodes (`Event.<Callback>` for `Return.<Callback>`, `Method.<Name>` for `Return.<Name>`): a `Return` another function's event reaches is refused, naming that event node;
- a `Return` is never reached through a `Flow.Delay`'s `Later` flow (which runs after the function has returned), naming the `Flow.Delay` node.
The checks run when the exec links form no cycle (as the dominance rules), one walk per function present among the events, only in a graph that holds a `Return` node. The method declarations' rules are `ValidateGraphStructure`'s (decision 1). `FindGraphTextLimitIssues` lays out the new lines with the rest, so the depth and size limits measure them.

### 6. The world-pause opt-in (W39.1)

`RunsWhileWorldPaused` true makes the transpiler write `Graph.RunsWhileWorldPaused = true` on the line after the `Graph.Fields` block; false writes nothing, so every existing text stays. The graph's behaviour then runs its `OnFixedUpdate`, `OnUpdate`, `OnLateUpdate` and tasks while the world is paused, as a Luau class that sets it (ADR 0050 decision 2). This closes `Docs/Backlog.md` §6's graph row on the world pause.

### 7. Modules: the documented answer (the owner's answer 3)

A graph still requires nothing (`Docs/Backlog.md` §6's row stays, reworded): it reaches shared behaviour through a behaviour instance, `Call.Scene.FindByPath` → `Flow.IfNotNil` → `Call.Entity.GetScript` → `Script.Get` or `Script.Call`, and the engine's pause through `Call.Time.IsWorldPaused` or the opt-in. The game-building skill's `graphs` page shows the chain.

### 8. Automation (W39.1; no new method)

- **`graph.setMembers {graph, name?, rename?, remove?, fields?, variables?, methods?, runsWhileWorldPaused?}`**, applied in this order: the name; the renames; the removals; the fields; the variables; the methods; the opt-in. `GraphSetMembersParams` gains `Methods` (a list of free-form values, departure 1) and `RunsWhileWorldPaused` (bool; absent keeps the graph's), appended.
  - `methods`: each item is read strictly through the registry's `"GraphMethod"` struct (an unknown member, a wrong type or a bad enum refused at `/methods/<i>/...`), checked alone by `ValidateGraphStructure` (its rules located below `/methods/<i>`, a second result at `/methods/<i>/Results/1`), and added or replacing the method of its name. A method may not take a field's or a variable's name (refused at `/methods/<i>/Name`).
  - A replaced method's signature change is refused while a link or a literal needs the old one: an issue of a `Method.<Name>` node at `/methods/<i>/Parameters`, of a `Return.<Name>` node at `/methods/<i>/Results`.
  - `rename` extends to methods: a method's rename rewrites its `Method.<Name>` and `Return.<Name>` nodes, keeping their ids, values and links, and counts them in `renamedNodes`; the new name follows the method rules (refused at `/rename/<i>/to`).
  - `remove` extends to methods: refused at `/remove/<i>` while a `Method.<Name>` or `Return.<Name>` node uses it, naming the nodes.
  - A method's name is a string at its callers (`Script.Call`'s `Method` in other graphs, Luau's `:Name()`), which no rename rewrites (documented in the method's description, §13.5 and the skill).
- **`graph.read`'s document** carries `RunsWhileWorldPaused` and `Methods` (the `"Graph"` struct, fully typed).
- **`graph.nodes`** lists `Script.Get`, `Script.Set`, `Script.Call`, `Self.Instance` and the `Return.<Callback>` kinds, and with `graph` also that graph's `Method.<Name>` and `Return.<Name>` kinds; its description names them.
- The wire changes are additive; `Tools/MCP/catalog.json` and `Docs/Reference/*` are regenerated; `RegisterMethods.cpp` and `test_schemas.py` do not change (126 methods after M37, 86 proxied tools).

### 9. The importer and the versions (W39.1)

`GraphImporter::Version` stays 1: a graph without the new features transpiles to byte-identical text (decisions 4 and 6), so by ADR 0035 decision 10 nothing re-imports on the importer's account and no `.meta` changes; a graph rewritten at version 2 changes its source bytes and is imported again by its source hash, to the same text. The importer's comment names format 2. Every other format is unchanged (ADR 0052's ledger). The type registry exports every registry enum as a Luau type, so `Engine.d.luau`'s `GraphValueKind` gains `"Any"` (departure 5): the declarations' hash moves and every script and graph imports again once, to the same cooked bytes, as any sibling's new script member makes them; no binding changes.

### 10. Determinism

Nothing new reaches the state hash: graph methods, `Return`s, `Script.*` and the opt-in are transpiled Luau, and instance tables are outside the hash as every script's are. A graph method runs exactly as its Luau text would, in its caller's callback and phase (no `PlaySessionPhase`, ADR 0052's ledger). Rolling Ball's `Checkpoint.graph` keeps its text, so its three replays keep their hashes (a replay's fingerprint names the graph's cooked hash, which is unchanged, and is compared only when the state hash differs).

### 11. Live values

`Script.Get`'s `Value`, `Script.Call`'s `Result` and `Self.Instance`'s `Value` are probed as every computed value (a table, a function or a proxy as null with its type name); `Method.<Name>` outputs (the parameters) stay unprobed, as M24's event outputs.

### 13. The Graph Editor (W39.2)

Its side panel gains a **Methods** section (each method's name, parameters and result; add, rename and remove, through `graph.setMembers`) and a "Runs while the world is paused" checkbox (`graph.setMembers {runsWhileWorldPaused}`, `EditorCore/Graph/GraphEditorRequests`' `MakeGraphWorldPauseRequest`). Since the canvas writes the whole param struct, whose opt-in is false by default, its members edit leaves `runsWhileWorldPaused` out (W39.1, so no members edit of the panel clears a graph's opt-in; "GraphEditorRequests: a members edit keeps the graph's world-pause opt-in, which the checkbox's request sets"). The canvas draws a `Return` without an exec output, `Script.*`'s `Member` and `Method` as String literal fields and the new kinds from `graph.nodes`, as it draws every kind from its pins. ## Departures from ADR 0052

1. **`graph.setMembers`' `methods` is a list of free-form values** (the lead's approval, 2026-11-17). An inlined `GraphMethod` list (two `GraphValueKind` enums) would grow `graph_set_members`' compact MCP input schema from 3,384 to about 4,800 bytes, past `test_schemas.py`'s 4,096; so the param is a list of Variant values, each read strictly through the registry's `"GraphMethod"` struct, its problems located at `/methods/<i>/...`, as §13.8's compact schemas treat component values. `graph.read`'s result and `Graph.schema.json` keep the full `GraphMethod` type, and the param's description names the struct. Tested: "GraphMethods: graph.setMembers refuses a malformed method at its pointer".
2. **A method's result is `Results`, a list of at most one `{Kind, AssetType}`** (the lead's approval, 2026-11-17), instead of ADR 0052's `Result: {Kind, AssetType} | null`: the type registry that reads and writes graphs has no optional struct member. An empty list is "no result"; a second entry is refused at `/Methods/<i>/Results/1`. Tested in "GraphDocument: a method's declaration follows the method rules, each violation at its pointer".
3. **A method's parameter is the local `p_<Name>` in the text** (ADR 0052 writes `<param>`): a graph identifier may be the name of a global the text uses (`Color`, `Log`, `vector`, `Assets`) or of a generated local (`n3_Result`, `o7`, `flow4`), which the parameter would shadow; the prefix shadows nothing. Callers pass arguments by position, so the prefix is invisible to them.
4. **A parameter's or result's kind is never Enum or Array** (ADR 0052 says "typed by kind"): an Enum needs choices the declaration does not carry, and an Array is a table an Any carries. And a parameter is never named `Then`, the exec output of its `Method.<Name>` node, whose data outputs the parameters are.
5. **`Engine.d.luau` changes in one line** (ADR 0052: "the script API and `Engine.d.luau` are unchanged"): the reference generator exports every registry enum as a Luau type, and `GraphValueKind` gains `Any`, so `export type GraphValueKind` gains `"Any"` and the declarations' hash moves (decision 9). No binding, callback or namespace changes; the script API is as ADR 0052 says.
6. **A `Return` entered by several exec links is a merge as any other statement is** (the review of W39.1, finding 2, and of W39.2, nit 5), where ADR 0052 decision 3 writes it "at each entry, never made a flow function": its flow function sets `result` and returns true and each entry calls it (decision 4). One code path lays out every merge, `FindGraphTextLimitIssues` measures the same layout the transpiler writes, and the text is correct and strict-clean (`Tests/Data/Graphs/Paths.graph`'s `Pick`, running and checked).

## Risks

- **Returns in the flow model** (ADR 0052's risk). Several event nodes and `Flow.Delay`'s later flows give a result no single meaning; the rules give Luau's meaning (a `Return` ends its function, merges propagate it through a flag, `Later` is refused), the text keeps `return` last in a block of its own, and every fixture text passes the strict checker; the depth and size limits measure the new lines.
- **Type checking moves to run time.** `Script.*` work on `any`, so a misspelt member reads nil and a misspelt method is a located run-time error; a method rename does not follow string callers. Mitigated by the located errors, live values and the skill page.
- **`tostring` of a table** (`Docs/Backlog.md` §6) is easier to reach through `Text.Concat` of an Any; text holding an address that reaches hashed state would split replays. The skill warns.
- **Format 2 rewrites every graph:** FeatureTest's four, Rolling Ball's, the test fixtures, and World Tree's after the landing; a missed rewrite fails `Scaffold.py --check`, the games suite's upgrade dry run or the provenance audit.
